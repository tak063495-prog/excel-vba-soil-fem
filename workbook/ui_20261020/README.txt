2D Soil FEM / 操作補訂 20261021_UI_05

2DSoilFEM_ui_20261020.xlsmとsoilfem_native_x64.dll（1個）を同じ新規フォルダーへ展開します。ファイル名は保持しています。
信頼できる取得元を確認し、WindowsデスクトップExcelで開きます。DLLは64bit Excel用。保護設定を全体で無効化しないでください。

初回実習は最新120ページPDFの9ページから。道路の入力・計算済みコピーはmanual-review/road_ui05_workbook.zipです。汎用原版の入力と混ぜません。
載荷B列は5キーワードまたは実在する正の整数節点ID。DISP=0はゼロ変位拘束で、無効化ではありません。
保存される連続体応力・ひずみ増分は圧縮正。塑性クロスは正=青/内向き、負=赤/外向き。旧UI_04は色と矢印の対応が逆でした。
ゼロ局所変位の材料更新省略時に前回の塑性増分を再掲しないよう修正。材料履歴・収束条件は保持しています。
数式を含む設定を危険に並べ替える移行は変更前に停止。元ブックを保存して設定キー位置と参照を確認します。数式の一般的な自動移行機能ではありません。

計算部20261020_INCO_ELEMENT_01、DLL同一。Double・材料則・Newton/GMRES収束・SRM探索条件は変更していません。
UI_05は38項目の実Excel確認、道路2条件×11工程で全節点/GP/工程結果の旧版一致、保存再表示とA/B再描画を検証。
ゼロ増分/スナップショット/クロス符号は専用の合成観測テスト。実塑性保持工程・全SRM再探索の新規回帰や初心者の手入力試験を完了したという意味ではありません。
本原版の保存結果は旧計算の例です。入力を変更したら最初から再解析してください。
Fs区間は数値収束の境界。設計安全率・物理的崩壊や実物の移動量の保証ではありません。
