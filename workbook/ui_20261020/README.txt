2D Soil FEM / 入出力画面 20261020_UI_04

2DSoilFEM_ui_20261020.xlsm と soilfem_native_x64.dll 1個を同じフォルダへ置きます。
ZIPは新しいフォルダへ展開し、旧版のDLLと混ぜず、新しいExcelプロセスで開いてください。
DLLは64bit Excel用です。DLLなしのVBA実行も維持しています。

出力・表示では結果を内容名から選びます。
最大せん断ひずみ増分・塑性主ひずみ増分クロスは個別のチェックボックスで追加できます。
初期はA：選択結果への等値線追加。B：増分専用カラーにも切り替えられます。
クロス倍率は1を入力済み。赤=引張・外向き、青=圧縮・内向き。
対象は最終収束荷重増分、SRMは最後の成功Fsです。累積ひずみとは区別してください。
新しい増分図には本版で最初から再解析が必要です。新しい保存結果は再読込後も表示できます。
旧結果の通常の応力・変位図はチェックなしで表示できます。
詳しい定義・実計算図・検証：リポジトリ docs/STRAIN_INCREMENT_DISPLAY.md。

操作順とタブ順：材料 → 形状入力 → メッシュ設定・確認 → 接合 → 載荷 → ステージ → 解析設定 → 結果。
簡易メッシュ生成は廃止しました。「形状入力」の座標・境界・格子間隔を使います。
「形状メッシュを作成」の後は図を自動表示します。赤いX/Yの拘束方向と品質値を確認してください。
品質修正候補は採用するまで元の節点・要素を書き換えません。採用すると更新後の図を表示します。
既存メッシュを使う場合は作成を省略し、操作パネルの「解析前：メッシュを確認」を押します。
図の下の「このメッシュで解析を開始」で解析を始めます。モデル変更後は再確認が必要です。
ボタンは説明文から離した空白領域へ配置しています。

入力813項目・保存互換性406項目・メッシュ操作91項目・表示108項目を確認。
ExcelでVBA全体と検証コードのコンパイル、保存後再読込も確認しました。
通常のDLL/I/O設定9項目はAUTO/1。材料・荷重・支持・Fs・収束条件は元の値を保持しています。
旧簡易メッシュ10設定は非表示で値だけ保持し、生成・入力検査には使用しません。

計算版 20261020_INCO_ELEMENT_01。Double・材料則・Newton/GMRES収束・SRM探索条件は維持。
旧2DLLとの固定Fs 8ケース（INCONSISTENT/DAVIS）とSRM全探索で、Fs・全変位・残差・診断CSVが完全一致。
SRM全探索例：Fs区間2.2000～2.2125、全170変位の差0、相対残差6.5595364013624E-13。
増分保存追加の同条件SRMは旧38.91秒（1回）、新39.92秒・43.04秒（2回）。高速化率は主張しません。

結果を見る前に：配布時の数値・図は前回計算の例です。入力を変更した場合は再解析してください。
Fsの収束区間は数値計算上の判定で、物理破壊・設計安全率の確定値ではありません。
単位を統一してください（例 m・kN・kPa、角度deg）。2D平面ひずみ・小ひずみ・全応力です。
浮力・水位・連成圧密は未対応。JOINTの塑性すべり・除荷履歴は未対応です。
出力先はブック名_out。EXPORT_LOADは空欄=新規、AUTO/フォルダ名=再開です。
