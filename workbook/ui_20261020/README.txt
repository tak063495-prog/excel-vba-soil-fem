2D Soil FEM 入出力整理版 / 2026-10-20

起動するファイル: 2DSoilFEM_ui_20261020.xlsm
DLL 2個をXLSMと同じフォルダに置いて、デスクトップ版Excelで開きます。
「操作パネル」→「初めに：対応機能・手順・結果の読み方」から操作ガイドを確認してください。

入力: 材料 → メッシュ・支持 → 接合（任意）→ ステージ・載荷 → 解析設定。
黄色C列が設定入力、緑G列が推奨・目安、灰色は自動出力です。
83設定を整理し、DLL・I/Oの9設定にはAUTO/1を入力済みです。
「高速化設定」下部のボタンはこの9項目だけを推奨値に戻します。
材料・荷重・支持・Fs・ψ・収束条件は変更しません。
SRM_TOL=0.02、SRM_PSI_POLICY=KEEPは元ブックから維持しています。

「解析設定」のチェックボタンは設定の形式・範囲を確認します。
材料・節点・要素などの整合性は解析開始時に検査します。
手動計算時も設定式を再評価し、不正な貼り付け値は解析前に拒否します。

結果: 成功/失敗とFs区間をステージ結果で確認してから、診断・全変位・応力・図を読みます。
配布時の数値・図は前回計算の例です。入力を変更した場合は必ず再解析してください。
保存先は「ブック名_out」。EXPORT_LOADは空欄=新規、AUTO/フォルダ名=再開です。

2D平面ひずみ・小ひずみ・全応力。浮力・水位・連成圧密は未対応です。
JOINTはpsi=0の履歴なし応力上限モデルで、塑性すべり・除荷履歴は未対応です。
単位系は統一します（例 m・kN・kPa、角度deg）。

計算版: 20261020_INCO_ELEMENT_01 / 入出力画面: 20261020_UI_02
Double、材料則、収束条件、SRM条件は維持。DLL 2個は要素行列積高速化版と同一です。
VBAコンパイル・保存前後のソース照合・再読込と、入力813項目/保存・互換性407項目を確認。
