# メッシュ品質改善とNewton反復継続

## メッシュ

デローニの仮想頂点を実頂点の追加領域から分離し、2,000点を超える生成で仮想頂点が上書きされる不具合を修正した。POLY2の隣接辺登録も修正した。未使用の形状座標は入力を残して生成対象から除外する。

品質目標と幾何学的な有効性を区別する。反転・退化・共有辺不整合は停止し、形状目標未達は警告として残す。絶対面積・絶対Jacobianのサイズ警告だけを理由にT6化しない。

| 形式 | 既定の形状目標 |
|---|---|
| Q8 | 最小角45°、最大角135°、辺長比5以下、4×最小Jacobian/面積0.1以上 |
| T6 | 最小角20°、最大角140°、辺長比5以下 |

Q8角度修正後、局所細分化候補を評価し、改善した候補だけを採用する。残る不適合Q8はオプションでT6へ置換し、対角線を比較する。T6は同一材料内の辺交換、節点移動、局所パッチ再構成を試す。Q8の形状目標、材料境界、外周、条件付き節点を保持する。直線境界上では同じ線分内の移動に限る。再構成でIDを詰める場合は条件も追従する。

`MESH_QUALITY_REFINE` は局所細分化、`MESH_T6_FALLBACK` はT6切替、`MESH_T6_PATCH_ENABLE` は周辺節点改善、`MESH_T6_PATCH_REBUILD` は局所再構成を指定する。水理・接合・ID参照の条件を安全に追従できないモデルでは局所パッチ処理を省略し、理由を記録する。鋭角の入力境界を細分化しても、その角度自体は変わらない。混在メッシュの塑性域適応再分割は対象外。

## 反復継続

`NEWTON_PROGRESS_CONTINUE=1` が既定。通常のNewton上限到達時に、受理した反復の自由度相対残差を確認する。直近の1回と確認窓全体で残差が低下していれば、`NEWTON_PROGRESS_WINDOW` 回ずつ上限を延長する（既定20、範囲2～1000）。固定の総延長回数は設けない。低下率による足切りは行わず、数値として表現できる低下を改善として扱う。同値は改善に含めない。

収束判定の許容残差・変位補正条件は変更しない。停滞・増大・非有限値・材料更新失敗・行列解法失敗・手動中断の保護を残す。棄却した試行を改善履歴へ入れない。増分、切戻し、連成の各機械解法の開始時に履歴を初期化する。通常の荷重解析とFIXED_STRESS内のNewtonに適用する。FIXED_STRESS外側の連成収束条件は別の判定である。

非関連流れの停滞判定と弾性補正の予測回数判定も、実際に残差が低下している場合は打ち切り理由にしない。`NEWTON_PROGRESS,EXTEND` ログに反復番号・残差・次回確認回数を記録する。`NEWTON_PROGRESS_CONTINUE=0` で従来の回数上限に戻せる。

## 検証

`tests/check_newton_progress.py` は本番VBAの進捗制御を隔離したExcelで実行し、100回・1000回の従来上限を超える低速残差低下、停滞、増大、丸め変動、無効残差、履歴初期化、重複・古い試行、無効設定を確認する。`tests/mesh_quality_regression.bas` は形式別品質、辺交換、混在要素、局所細分化を確認する。`tests/test_nonfinite_regression.py` は非有限値の検証器を確認する。

実モデルの開始確認は、配布ブックの検証用コピーで実際のNewton補正を実行して確認する。開始確認の成功は、重力解析全体・SRMの収束や設計妥当性の保証を意味しない。

検証コマンド例（Windows、Excel、pywin32、既存のネイティブDLL付きブックを用意）:

```powershell
python tests/check_newton_progress.py
python tests/run_mesh_quality.py regression --book C:/work/base.xlsm
python -m unittest discover -s tests -p test_nonfinite_regression.py -v
```

SRMの保存・復元比較では、従来と同じ探索経路を比較するため検証用コピーだけ `NEWTON_PROGRESS_CONTINUE=0` とする場合がある。反復継続自体はONの別テストで実行し、結果を混同しない。配布ブックはON。
