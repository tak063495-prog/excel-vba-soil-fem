# 形状メッシュへの統一と操作順の整理（UI_03）

配布名は `2DSoilFEM_ui_20261020.xlsm` のままです。ZIPを新しいフォルダへ展開し、同梱の **soilfem_native_x64.dll 1個**をブックと同じ場所に置きます。旧版のDLLと混ぜず、新しいExcelプロセスで開いてください。

## 入力と確認の順序

左から「操作パネル」「操作ガイド」「材料データ」「形状入力」「メッシュ設定」「接合」「載荷」「ステージ」「解析設定」「高速化設定」「出力・表示」「詳細設定」「図」「ステージ結果」「接合結果」の順です。数値結果・節点・要素・診断は操作パネルのボタンから開けます。

1. 「材料データ」で材料と単位を確認します。
2. 「形状入力」で座標、外側／内側境界、節点順、格子間隔を指定します。
3. 「メッシュ設定」で材料番号・外周の拘束・生成方式を確認し、「形状メッシュを作成」を押します。簡易メッシュ生成は廃止しました。
4. 作成後は「図」が自動で開きます。形状、要素、赤いX/Yの拘束方向、品質目標と品質集計値を確認します。予定色は有効なステージのBIRTH/DEATHに対応します。
5. 品質修正が必要なら「品質修正候補を確認」へ進みます。候補は採用するまで節点・要素を書き換えません。「取消」はメッシュ設定へ戻り、「採用」は更新後のメッシュ図を表示します。
6. 接合・載荷・ステージ・解析条件を確認してから、操作パネルの「解析前：メッシュを確認」を押します。**この時点では解析を開始しません**。
7. 図の下の「このメッシュで解析を開始」を押すと解析を始めます。確認後にモデルが変更されていれば再確認表示を行います。
8. 計算後はステージ結果の成否・Fs区間を読み、数値結果と「出力・表示」の変形・応力図を確認します。

既存の節点・要素をそのまま解析する場合は、形状メッシュの作り直しを省略し、操作パネルから確認表示へ進みます。メッシュ作成は既存の節点・要素を更新する操作です。

品質目標のPASSは解析結果・安全性の保証ではありません。WARNや評価エラーが表示された場合は原因を確認してください。解析開始時の入力整合性検査は引き続き実行します。

## 入力値と互換性

Double、材料則、収束条件、SRM探索条件は変更していません。通常のDLL・I/O推奨設定はAUTO/1です。材料・荷重・支持・Fs条件は元の値を保持します。

旧簡易メッシュの `MESH_POINT*`、`MESH_NX`、`MESH_NY` は、既存ブックとの互換性のためメッシュ設定の非表示行に値を保持しています。生成・入力検査には使用しません。形状メッシュは「形状入力」の座標・境界・格子間隔を使います。共有の材料・外周拘束設定は有効です。

ボタンは説明のセルから離した専用の空白領域へ配置しています。検証にはセル・ボタンの矩形比較とExcel実画面の確認を使用しました。

[詳細PDF説明書](manuals/2DSoilFEM_Detailed_Manual_20261020.pdf)にも現行の形状メッシュ操作・DLL1個・施工例・増分図を反映しました。[改訂内容](manuals/README.md)も参照してください。

## DLL統合と検証の再現

MSVCの計算カーネルと、従来と同じGCC14/x87精度フラグで作成した材料カーネルを1個にリンクしています。材料コードの倍精度演算や収束判定は変更していません。旧2個構成との比較は、ライブラリ名とDLLハッシュ以外の差を許さない専用比較で確認します。

```powershell
cmd /c native\build_combined.cmd
pwsh -NoProfile -File tests/build_workbook_ui.ps1 -OutputDirectory tests/tmp/new_ui_build
pwsh -NoProfile -File tests/test_shape_mesh_workflow.ps1 -Book tests/tmp/new_ui_build/2DSoilFEM_ui_20261020.xlsm
pwsh -NoProfile -File tests/native/build_combined_probes.ps1 -OutputDirectory tests/tmp/new_probe_build -Count 100000
```

Excelを使うテストは、別のExcelが起動中なら開始しません。元ブックを変更せず専用コピーを使用します。検証用に注入したVBAも実行前にExcelでコンパイルします。文字列連結の `&` を識別子に密着させると型指定文字として解釈される場合があるため、検証コードの連結には空白と関数の括弧を明示しました。

生の数値検証記録は [shape-mesh-evidence/20261020](shape-mesh-evidence/20261020) にあります。材料点20万件、材料GMRES、SIMD・tuned・prepared GMRES、INCONSISTENT/DAVIS固定Fs、SRM全探索を含みます。リンク時のLNK4078（MinGW/MSVCの`.drectve`属性差）は記録したうえで、ABIと実計算で検証しています。
