# 1024版を基礎とする水理変動・時間圧密ステージ実装計画

実装前の設計記録。現在の操作・対応範囲は[工程ごとの時間圧密・水位変動](FIXED_STRESS_STAGES.md)、検証記録は[受入検証](FIXED_STRESS_VALIDATION.md)を参照。

## 1. 方針

1024版の7画面と工程の追加・複製・削除・並べ替えを維持し、施工操作と水理・時間の指定を独立させる。水位を変える工程だけでなく、盛土・載荷で発生する過剰間隙水圧と、その後の消散も扱う。計算精度はDouble、既存の材料則・力学収束条件・SRM探索条件を維持する。

地下水位を一定にするとは、指定した水位・水頭の境界条件を次の変更まで継承することである。内部の間隙水圧を全点で固定することではない。境界水位が一定でも、時間を進めれば載荷による過剰間隙水圧は消散し、変位と有効応力が変化する。

この文書は今後の実装仕様を定める。現行1024版の`ONE_WAY`機能は保持し、未実装の連成を既存ブックの設定だけで有効化しない。

## 3. 工程の入力

### 3.1 工程の役割

|項目|入力・選択|動作|
|---|---|---|
|施工操作|既存の盛土・掘削・載荷・除荷・WATER・SRM等、および「時間経過」|何を変えるかを指定。時間経過は施工条件を変えずに時間を進める新操作|
|水理・連携方式|継承／片方向／時間連成（fixed-stress）|既存の片方向を保持。初回の時間連成は初期状態を明示し、以後は受理済み状態を継承|
|境界水位|継承／登録済み水位線ID|未変更の工程では継承。左右や構造物前後で異なる境界群を指定できる|
|水位の変化|保持／工程開始で変更／工程時間内で線形変化|折れ線の空間形状と時間変化を分ける。中間時刻の折れ点も詳細表で設定|
|工程継続時間|数値＋秒・分・時・日の選択|工程ごとの時間。累積時刻は自動計算し、並べ替え後も再計算|
|排水条件|継承／排水条件セットID|境界水頭・水圧・流量・非排水を境界群ごとに指定|
|載荷の時間変化|開始時に作用／工程内で線形載荷|有限時間の施工中の圧密と、瞬時載荷後の圧密を区別|
|計算・保存設定|初期刻み・最小／最大刻み・保存間隔等|通常はプリセット、必要時に詳細を編集。画面には実際の採用値を表示|

「水理変動」はWATERの画面上の名称とし、時間を伴う場合はfixed-stressで進める。既存の時間なし片方向WATERも残す。ただし時間連成開始後に片方向で水圧を再計算し、残存過剰水圧を暗黙に消す操作は拒否する。定常状態への移行は、時間経過での定常到達確認を基本とする。

工程継続時間0での盛土・載荷は、排水を進めない瞬時の連成応答として初期過剰水圧を求める。`Δt=0`を時間離散式へ代入しない。排水境界の指定は維持し、未知圧力部分について流出を伴わない初期応答を解く。初期応答と小さい正の時間刻みの極限を照合する。

盛土のBIRTHは要素の有効化・自重載荷・初期水圧を別に扱う。要素剛性を曖昧に徐々に増やす方式は使わず、施工層を分けた工程で形状の進行を表す。各層の自重載荷には施工時間を指定できる。

## 4. 材料・初期条件・水理境界

### 材料

- 地盤は有効応力に基づく排水骨格のE・νと既存の強度・流れ則を使用する。非排水νや全応力強度を圧密材料へ無条件に流用しない。
- 材料別に透水係数`kx, ky [m/s]`、Biot係数`α [-]`、貯留`1/M [1/kPa]`を持たせる。基本はα・Mの直接入力、詳細は間隙率n・粒子体積弾性係数Ks・水の体積弾性係数Kwから算定し、算定値を表示する。直接値と算定値は排他的とする。
- 透水係数と固有透過率`[m²]`を混同しない。水の単位体積重量は既存のkN/m³体系へ統一する。骨格変形による貯留と流体・粒子の圧縮を二重に加えない。
- 土の重量は既存と同じ全重量を使用し、圧力による有効応力・外水圧・浮力の二重控除を防ぐ。構造体を圧密土へ自動変換しない。
- 既定値を入れるのは時間刻み等の数値制御に限る。未設定の物性に仮の透水係数・圧縮性を埋めて計算を続けない。

### 初期状態・境界

- 初期地盤は静水圧／定常浸透で初期水圧を定め、自重と整合した初期平衡を確認してから施工を開始する。定常浸透の結果は静水圧とは限らない。
- 圧力pは全間隙水圧として持ち、過剰水圧は明示した基準場との差として出力する。境界変動中に基準を無言で変更しない。全水頭は`h=y+p/γw`として表示する。
- 非排水は法線流束0であり水圧0ではない。排水境界のp=0は大気圧ゲージ条件であり、水面下の境界には指定水頭に対応するpを与える。
- 境界群ごとの水頭差を保持し、遮水壁の両側を共通圧力自由度で短絡させない。閉鎖水理領域は貯留・初期水量・境界の整合を検査する。
- 構造体・空洞・内水位・外水位に対する圧力荷重は同じ時刻で更新する。地盤の有効応力項、接触面水圧、構造体外力の重複を検査する。
- JOINTは、連続／遮水／指定水圧の水理接続と力学的な接合状態を別に扱う。開口に応じた透水性変化は別の検証項目とする。

## 5. 計算処理

基礎は小ひずみ・準静的な飽和Biot連成とする。引張正の記号では`σ=σ′−αpI`、流量は`q=−(k/γw)∇(p+γw y)`、流体の収支には`α dεv/dt+(1/M)dp/dt+div(q)`を用いる。実装では現行コードの応力符号へ変換し、符号の単体検算を行う。

1. 直前の受理状態を複製し、当該時刻の施工荷重・水頭・排水条件を設定する。
2. 後退Eulerを基本とする時間離散化により、固定応力の安定化項を含む流体問題と力学問題を反復する。安定化係数は材料のα・排水体積剛性を基に決め、線形基準解と塑性ケースで検証する。
3. 各力学評価は同じ受理済み履歴から試行する。連成反復のたびに塑性履歴を累積コミットしない。
4. 水圧・変位の反復差だけでなく、安定化項を除いた元の流体方程式の残差、力学残差、全体水量収支を確認する。力学側の既存収束判定は維持する。
5. 合格したときだけ水圧・変位・応力・塑性状態・時刻を同時に受理する。不合格なら全状態を戻して刻みを縮め、最小刻みで不合格なら停止理由と最後の受理状態を保存する。
6. 保存対象時刻・水位時系列の折点・工程終了時刻に必ず着地する。反復が少ないことだけで刻みを過大にせず、時間刻み収束も確認する。

fixed-stressは流体計算と力学計算を一度ずつ行うだけの片方向計算ではない。[Kimらの固定応力分離法の研究](https://doi.org/10.1016/j.cma.2010.12.022)を基礎とし、既存の圧密コードを独立に再検証する。線形理論の安定性を、任意の塑性・施工変化・時間刻みでの精度保証とは扱わない。

圧力の全結合行列、貯留行列、変位との結合、境界消去を独立実装で照合する。低透水・小刻み・ほぼ非圧縮条件での圧力振動も確認する。既存Q8/Q4の骨格を再利用しても、圧力行列の縮約や対角化が正しいとは事前に仮定しない。

## 6. SRMと施工状態の引継ぎ

SRMは直前に受理した施工状態を親とする照査枝で実行する。基本仕様は、親状態の水圧分布を保持する短時間の有効応力SRMとする。強度低減中に圧密時間を進めず、SRMによる追加の過剰水圧も計算しない。この条件を結果に表示し、排水SRMや非排水連成SRMとは区別する。

各Fs試行には同じ親状態を復元する。照査後は、強度低減前の材料・変位・全／有効応力・塑性履歴・水圧・時刻・有効要素・荷重・排水条件を本線へ戻す。最後の失敗試行や、最終収束した強度低減状態から次の施工を開始しない。

BIRTH／DEATHは、圧力自由度と水理接続を更新し、残存要素の履歴を保持する。新規材料の初期水圧・初期応力、除去領域の水量、掘削面の排水・水圧を明示し、水量収支では領域増減による持込み・持出しを通常の境界流出入と分ける。掘削面を自動でp=0にしない。

水理を伴うRESET_U／RESET_STRESS／MATSETは、物性・基準座標・履歴・貯留水量の変換則を定義し検証するまで現行どおり停止する。再メッシュ時の履歴補間も初期対応へ含めない。

## 7. 結果と保存

- 状態の識別子：工程ID、工程内時刻、累積時刻、受理状態ID、親状態ID、照査枝ID。
- 時間履歴：指定点の沈下・水平変位・水圧・過剰水圧、境界別流出入、貯留変化、水量収支、反力。
- 分布図：変形、有効／全応力、全間隙水圧、過剰水圧、全水頭、Darcy流束、既存のせん断ひずみ増分・塑性主ひずみ増分。
- 図の表示：入力水位と境界条件、計算水頭・水圧を別表示する。等水頭線を自由水面と呼ばない。圧密度は定義と基準を併記し、複雑な多段載荷へ一律に適用しない。
- SRM：親の工程・時刻、水圧保持条件、Fs区間、収束／非収束と残差を表示する。SRM図と本線施工図を取り違えない。
- 計算ログ：実刻み・再試行・連成反復・流体／力学残差・水量誤差・処理時間を記録する。
- チェックポイント：圧力・時刻・貯留履歴・水理接続・境界・入力署名を既存保存へ追加。再開は受理状態からのみ行う。旧形式の計算結果は、圧密履歴があるものとして読み替えない。

大規模な時刻別全場をワークシートへ常駐させず、外部CSV等の結果保存と選択時読込を基本とする。指定点履歴と要約はExcel内で扱う。履歴全体の密行列化は行わず、組立・分解の再利用は材料・有効要素・境界・Δtが同じ範囲に限定する。DLLを拡張する場合も配布DLLは1個とする。

## 8. 対応範囲と実装順序

|段階|実装・判定|
|---|---|
|1：数値基盤|飽和・線形弾性Q8/Q4、材料別物性、非定常流体・fixed-stress、初期平衡、保存再開。独立基準解に合格してから工程へ接続|
|2：施工工程|既存MCのDAVIS／INCONSISTENT、載荷・盛土・掘削・時間経過・水理変動、全状態継承とSRM照査枝、構造体・空洞・JOINTの水圧荷重|

|4：回帰・公開|旧片方向・乾燥ケースの回帰、施工連成例、説明書の操作差分と検証記録を揃えて実装PR|

初期リリースは飽和領域が定義できる範囲とする。飽和地盤の境界水頭の時間変化は対象だが、水位低下で土中に不飽和領域が生じる場合や未知の自由水面の移動は別の数理モデルを要する。入力水位線を移動するだけで対応済みとしない。初期実装では適用範囲外を検出し、対象工程と理由を示して停止する。自由水面・不飽和・浸出面の自動切替は後続の独立拡張とする。

開口によるJOINT透水性変化、クリープ／二次圧密、有限変形、動的地震応答、軸対称・梁の新規連成、施工途中の再メッシュは本計画の初期対象へ含めない。
