# 1mモデルの自重解析の修正と検証（2026-11-28）

材料11・12をともにc=6,000kPaとした1mモデルの自重解析で、荷重係数1.0まで収束したことを確認した。今回の確認は自重ステージ終了までで、1m版のSRM安全率は求めていない。

## 原因と修正

旧処理は、塑性化した領域で残差ノルムが一時的に増える補正をすべて棄却していた。同じ停止点の剛性再構築前後は一致し、線形求解の相対誤差は2.69E-14だった。一方、alpha=0.25は残差ノルムを増やすが、関連流れ則の増分ポテンシャルを減らすことを実測した。同一メッシュの独立な応力つり合い診断でも解が得られ、最初の増分の変位をExcelの材料則で照合した。

- 乾燥・関連流れ則の対応範囲では、補正の選択に整合する増分ポテンシャルを使用する。最終収束の判定は従来どおり残差・変位補正・境界条件で行う。
- 接線が特異、または補正探索が失敗した場合は、補正方程式だけを一時的に安定化する。求解後に物理剛性を厳密に戻し、ばね力や強度を追加しない。回復の試行も各増分の50回上限に含める。
- 棄却された材料状態を復元した後、要素剛性の再構築フラグを必ず立てる。
- 検証済みブックに既に含まれていた準備メッシュ復元、入力検査、形状台帳・画面のソースを同期する。準備メッシュを使用する設定3以外のモデルには、専用の幾何形状を強制しない。

水連成、非関連流れ、接合、アワーグラス等で増分ポテンシャルを適用できない場合は、従来の残差探索を維持する。外部最適化ソフトは独立診断だけに使用しており、配布ブックの実行には不要。

## 維持した条件

- 1m間隔、節点24,568、T6要素12,117。準備メッシュを維持。
- 材料11・12のc=6,000kPaはユーザー指定の検証用仮値。そのほかの材料特性・形状・荷重・拘束・工程・設定を維持。
- 修正前後で入力・設定・準備メッシュ710,691セルと数式が一致。
- 最終残差基準1E-5、変位補正比基準1E-4、厳密残差基準1E-8を維持。
- 各荷重増分の全体反復上限50、ラインサーチ上限4、荷重増分と切戻し条件を維持。
- strict band DLLは従来と同じ。Doubleと構成則は変更していない。

## 実測結果

| 項目 | 修正前 | 修正後 |
| --- | --- | --- |
| Fs=1の自重ステージ | 未収束 | SUCCESS |
| 受理した荷重増分 | 0 | 8 |
| 到達した収束済み荷重係数 | 0 | 1.0 |
| 最終相対残差 | — | 4.618584221194E-11 |
| 最終変位補正比 | — | 2.916177662509E-7 |

修正後の自重ステージは545.168秒（約9.1分）。最初の荷重係数0.1は43回、最後の増分は11回で収束。全8増分が受理され、切戻しは0回。最初の増分だけで終了せず、標準の工程処理で荷重係数1.0とGRAVITYのSUCCESSチェックポイントまで確認した。

検証用コピーは自重成功後・SRM開始前に意図的に停止した。ログ末尾の`EXPECTED_GRAVITY_VERIFICATION_BOUNDARY`はこの終了目印で、配布Excelに停止コードは含まれない。最初の検証スクリプトの終了後チェックが載荷用変数を参照していた点も修正し、正式な自重CSV・SUCCESSチェックポイントで完了を照合した。

## 検証

- VBA全体コンパイル成功。配布ブックとリポジトリのVBAソースを照合。
- 物理剛性の対角復元誤差0。不釣合い剛体移動の対照ケースは補正後も収束条件を満たさない。
- 増分ポテンシャルの微分と実際の内力の整合誤差は約1.02E-11。
- 固定Fs、最小時間刻み、接合水圧、無効連成工程、連成列モデルの既存5ケースがPASS。
- 詳細な数値と監査：[検証記録](verification/srm_gravity_1m_20261128.json)。標準CSV・チェックポイントは配布ZIPに同梱。

再現（64ビットExcel、VBAプロジェクトへのアクセスが許可された検証環境、pywin32）：

```powershell
python tests/check_srm_gravity_delivery.py
python tests/check_srm_gravity_convergence_excel.py --book path/to/model.xlsm --out tests/tmp/gravity_run
```

`--out`は新しいフォルダーを指定する。入力ブックを直接変更せず、コピーで自重ステージを実行し、SRM前に停止する。

計算法の参考：[Bruno et al., associative plasticity and conic return mapping](https://web.tecgraf.puc-rio.br/~lfm/papers/HugoBruno-ApplMathModelling-2020.pdf)。この資料は数値手法の参考であり、本モデルの設計上の安全性を保証するものではない。
