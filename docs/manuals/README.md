## 今回の実計算と図

- 斜面上のL型擁壁と背面盛土：1857節点・580要素、DAVISの施工後SRM。A/B図はこの計算の同じ収束済み状態からExcelが生成したSVGです。変形倍率1で全有効要素の積分点Jacobianが正であることを確認しました。
- 流れ則比較：同じ3383節点・1074要素、同じ材料・支持・施工・DLL・出力・収束/SRM条件でFLOW_POLICYだけを切替。INCONSISTENTは時間で中断せず、ソルバー本来の終了まで実行しました。Fs区間の解釈、全6766変位成分、残差、各Fsの反復と時間を保存しています。DAVISは材料換算による近似であり、同じ材料則の速度スイッチではありません。
- アンカー相当力（INCONSISTENT）：擁壁の頭部と定着側へ等大反対向きの合力50kNを分配し、載荷後の施工状態とSRMを計算。合力・合モーメントが0であることも検査しました。専用アンカー要素、軸剛性、引抜き、自由長等の解析ではありません。
- アンカーの同入力DAVISは載荷工程4で非収束となり、SRMには進みませんでした。DLLをOFFにしたVBAでも同じ停止を再現し、DLL固有の不具合とは確認できませんでした。
- トンネル：土被り20m・掘削径8m・支保厚0.3m。497節点・160要素の共有Q8メッシュで上半/下半掘削と支保への切替、その後のSRMを計算しました。3次元切羽効果や専用応力解放率は表現しません。
- 道路拡幅の掘削・別材料再盛土は、現行原版のコピーで形状メッシュ作成から11工程をあらためて実解析しました。328節点・95要素、INCONSISTENT、3.932870秒。工程別の全節点変位、反力、自重、材料切替、図を新しい記録へ保存しました。今回の道路例は施工11工程で、新しいSRM安全率を主張していません。
- 水平地盤・斜面の支持力例は、載荷幅2mの一様な追加沈下1～50mmと反力の関係を16ケース実計算。粗688節点/209要素、細2629節点/836要素を比較。50mm時の細メッシュ平均圧力は水平364.9484kPa・斜面366.2651kPa、比較条件の粗密差の最大絶対値は3.1434％です。剛体基礎や片側接触はモデル化せず、極限支持力・許容支持力・現場載荷試験の観測値とは区別します。
- メッシュの点・境界・共有点・格子間隔の入力、品質修正候補の確認/採用/取消、修正後の載荷と材料の見直しをモデル入力章へ統合しました。

細メッシュINCONSISTENTの最終数値収束状態は、倍率1の変形後形状を11×11点で調べると一部要素が反転しました。厳格な形状検査は不合格です。この状態の変形図は見本に使わず、比較JSONと全変位CSVに警告を残しています。表紙・A/Bは形状検査に通った粗メッシュDAVIS例です。

トンネルのSRMはFs=3まで収束したLOWER_BOUNDで、非収束側は未取得です。最終支持反力と自重の差−0.00512311kNは自由節点の残差合計で説明され、両方を含む鉛直釣合い差は3.38e−9kNです。

壁・支保は連続体STRUCTです。仮の高い強度とI=0を設定し、保存された塑性増分0・降伏関数を検査しました。STRUCT名だけで弾性固定やSRM対象外になるわけではありません。土と壁は共有節点で接続し、この実例にはすべり・開口JOINTを入れていません。

通常の結果ボタンは最終工程を表示します。本書の施工段階図は保存された数値から再描画したものです。Excelで過去工程を比較する場合は、同じ初期入力のコピーで後続工程のE列を0にし、最初から計算する手順を用います。
