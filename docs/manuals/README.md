## 誤解しやすい制約

- `STRUCT` の名前だけでは線形弾性に固定されません。連続体の材料更新経路を通ります。弾性挙動を想定する入力例では塑性化を避ける仮の材料条件を示し、塑性成分・降伏状態の確認を求めています。仮の高い粘着力をコンクリートの設計強度として使わないでください。
- SRMの強度低減対象は材料I列で決まります。構造材のコピー元もI=0とする例です。`STRUCT` が自動的に低減対象外になるわけではありません。
- 専用アンカー・梁・トラス・支保工要素はありません。節点力の例は軸剛性、定着長、引抜き、降伏、変位に応じた軸力変化を計算しません。
- トンネル例は2次元断面の掘削後再釣合いです。専用の応力解放率、掘進面の3次元効果、吹付材齢等を再現した例ではありません。
- 現行の通常の結果表示ボタンは最終工程を表示します。過去工程の図を比べる手順は、同じ初期入力のコピーごとに最後の有効工程を変え、最初から再計算する方法です。説明書の更新で施工例専用ボタンを追加したわけではありません。
- L型擁壁・アンカー・トンネル・斜面擁壁SRMは**未計算の設定例・模式図**です。実際の設計や収束を検証したモデルとして紹介していません。

## 実計算図と記録

増分図A/Bは、すでに公開している85節点・20要素のSRM計算からExcelが描画したSVGです。Fs PASS=2.2000、FAIL=2.2125。同一の収束済み状態・荷重増分を、AはY方向応力と等値線、Bは増分カラーで表示します。塑性クロスは両図で同じ元データです。

元図・検証は [strain-increment-evidence/20261020](../strain-increment-evidence/20261020) と [増分図の定義](../STRAIN_INCREMENT_DISPLAY.md) を参照してください。PDFへの変換では元の図形・数値を保持し、日本語フォントを埋め込みました。

施工例の表は、前の作業で得た記録を引用しています。[construction-evidence](construction-evidence) のJSON.gzはgzip圧縮した元出力です。今回のPDF改訂に伴う再計算ではありません。

- `native_11_stages.json.gz`：DLLありの11工程。全変位、全工程の節点・要素結果、材料状態、実行時間等。
- `vba_11_stages.json.gz`：DLLなしの同一施工。最終656変位成分の最大差は約1.18×10^-16m。
- `history_probes.json.gz`：再BIRTH時の対象履歴初期化、対象外履歴・変位の保持、孤立自由度の計測。計測用のコピーであり時間比較には使いません。
- `optional_srm_undetermined.json.gz`：施工後にSRMを追加した既存試行。Fs=1.5で未収束、最後の収束試行1.4、区間未確定。安全率や確定下限として採用しません。
