上面高さは次式で表せる。

```text

領域：0 <= x <= 20, 0 <= y <= y_top(x)
```

### 3.3 メッシュ・荷重の入力チェック用の派生値 [D]

```text
斜面比高       = 10 - 4 = 6 m
斜面水平長     = 16 - 10 = 6 m
斜面角         = atan(6 / 6) = 45°
断面積         = 10*10 + 6*(10+4)/2 + 4*4 = 158 m²
単位奥行自重   = γ * 断面積 = 20 * 158 = 3160 kN/m
奥行1 mの自重  = 3160 kN
```

自重のみを与えた静的な収束解では、奥行1 mのモデルの鉛直反力合計が約+3160 kNになることを確認する。微小変形・単位奥行・重力下向きという本書の条件での釣合い確認であり、原論文が報告した反力値ではない。

## 6. SRMの低減則とF<1の扱い

### 6.1 低減式 [P：p.7、式(13)]

試行する強度低減係数をF（論文のSRF）とし、元の強度をc_0、φ_0とする。

\[
c(F)=\frac{c_0}{F},\qquad
\phi(F)=\arctan\!\left(\frac{\tan\phi_0}{F}\right),\qquad F>0.
\]

- φそのものをFで割らず、**tanφをFで割る**。
- 各試行では元のc_0・φ_0から計算し、直前試行の低減済み強度を再度割らない。
- 本ベンチマークではE、ν、γを変更せず、ψは0°のまま保持する。
- VBAの`Tan`・`Atn`へ渡す角度はラジアンとし、入力・保存のdegと相互変換する。

上記の実装上の扱いは、式(13)と本書の共通材料設定を数値入力へ対応させたもの。[D/V]

自重の載荷率λと強度低減係数Fは別変数である。λは0→1の荷重増分に用い、Fは材料強度に用いる。SRMを荷重倍率法へ置き換えない。[V]

### 6.2 材料低減の単体チェック [D]

Table 1のeSPFEM参照FOSをFとして式(13)へ代入した値。**SRMでこれらのFを必ず解として返す指示ではなく、低減式・単位変換のテスト値**である。

| Case | F | c(F) [kPa] | φ(F) [deg] |
|---|---:|---:|---:|
| Case1 | 0.68 | 14.705882353 | 7.331387537 |
| Case2 | 1.30 | 7.692307692 | 19.732818766 |
| Case3 | 1.18 | 16.949152542 | 4.240318700 |
| Case4 | 2.27 | 8.810572687 | 17.142978607 |

丸め前のDouble値で低減を計算し、表の桁数は照合用とする。

### 6.3 Case1は安全率1未満 [P/D]

論文のCase1の参照FOSは0.68である。したがって、このケースを扱うSRMドライバーは、**0<F<1の探索を許容する必要がある**。F<1では式(13)により元の強度を増加させる。

本ベンチマークでは次を必須とする。[V]

1. `F=1`で収束することを、SRMを開始できる前提条件にしない。
2. `F>=1`に探索を限定しない。
3. `F=1`の非収束を、ケース入力が誤っていると即断しない。
4. 初期探索点は実際に解析して確認し、参照FOSからPASS/FAILをハードコードしない。

## 7. 初期応力・載荷履歴の条件

### 7.1 論文に記載されている手順 [P：p.8本文]

論文は、粒子位置を固定して重力を与え初期応力場を得る段階と、粒子の運動を許し、初期破壊から新しい斜面形状での再平衡までを計算する段階を記述している。また、この例の崩壊後のシミュレーション時間は6 sとしている。

**対象節には、VBAへそのまま移植できる初期応力配列、K0値、重力導入の数値実装、減衰や収束閾値の一式は示されていない。** 「粒子位置固定」という記述を、通常の静的FEMで全変位自由度を固定して自重解析する操作へ、説明なく置き換えない。

### 7.2 高速化の回帰比較では、まず現行履歴を固定 [V]

既存のCase1～4のBaselineがある場合、初期応力生成、ステージ順序、各Fの開始状態、変位リセットの扱いを保存し、その履歴を高速化前後で維持する。初期化法の変更とNewton/LU等の高速化を同時に評価しない。

### 7.3 新規に統一試験を作る場合の手順案 [V]

既存履歴を引き継がず、入力から再現できる独立した準静的ベンチマークを作る場合は、`PER_FS_GRAVITY_RAMP`として次を定義する。

```text
各Case・各Fを独立に実行する。
1. 元の形状、変位0、応力0、塑性履歴0へ戻す。
2. 元のc・φから、そのFでの低減後材料を設定する。
3. 第4節の拘束を与える。
4. 自重をλ=0からλ=1へ増分載荷する。
5. 各増分で平衡と材料更新を確認する。
6. λ=1に到達したか、収束状態、変位・塑性域を保存する。
```

これはVBAの比較のために定義する載荷手順であり、**原論文の初期応力形成法と完全に同じとはしていない**。Case1でF=1の事前平衡を必須にしない構成でもある。

別Fの確定応力・塑性ひずみを無条件に引き継ぐ方法は、この独立試行と区別する。変位予測子等を使っても、基準の確定状態や載荷履歴を意図せず変更しない。

論文の6 sは物理的なシミュレーション時間であり、VBAの実行時間上限、6回の反復、6ステップの載荷を意味しない。今回の主対象は初期破壊時のSRM安全率であり、崩壊後の移動距離・再堆積形状は主たる照合対象にしない。

## 8. メッシュと離散化の条件

### 8.1 論文の記載 [P：p.7末尾]

```text
要素：6節点三角形要素
要素数：1417
節点数：2948
```

これは論文に記載された値をそのまま記録したもの。原論文のeSPFEMはひずみ平滑化・節点積分を用いており、通常のT6要素の積分法と同じと読み替えない。対象ページには全節点座標・全要素接続の一覧はないため、この情報だけでは原論文と同一のメッシュを復元できない。

### 8.2 VBA高速化の主比較 [V]

**現行VBAで使う要素形式・積分法とメッシュを固定する。** Q4を使う場合、原論文と離散化が異なることを記録し、同じQ4モデルの高速化前後を比較する。

4ケースには同じ節点座標・要素接続・自由度順序を使い、材料だけを変更する。各解析前に再メッシュして偶然異なる接続にしない。メッシュ変更や自由度並べ替えを高速化手法として試すときは、別の試験項目にする。

保存必須：節点数、要素数、自由DOF数、積分点数、接続・座標の識別値、自由度順序、行列帯幅、要素・積分法、ロッキング対策の設定。

### 8.3 新規の共通Q4メッシュを作る場合の再現可能な案 [V・任意]

既存メッシュが使えない場合の幾何学的に明確な代案として、次の写像格子を定義できる。最適メッシュ、原論文の再現メッシュ、精度保証済みメッシュとはしていない。

```text
i = 0,...,Nx,  j = 0,...,Ny
x_i   = 20*i/Nx
y_ij  = (j/Ny)*y_top(x_i)
node_id(i,j) = 1 + i + (Nx+1)*j

Q4の接続（反時計回り）：
(i,j), (i+1,j), (i+1,j+1), (i,j+1)
```

| メッシュID | Nx | Ny | 要素数 | 節点数 | 用途 |
|---|---:|---:|---:|---:|---|
| Q4-M1 | 40 | 20 | 800 | 861 | 小規模な実装比較の候補 |
| Q4-M2 | 80 | 40 | 3200 | 3321 | 細分化による結果変化の確認候補 |

いずれもx=10、16を格子線に含み、法肩・法尻を正確に表す。積分法は試験開始前に明示して固定する。これらへ変更した場合はBaselineも再計算し、旧メッシュの時間と同一モデルとして比較しない。

### 参照値の使い方 [V]

参照eSPFEMとの差は、例えば次式で報告する。

\[
e_{\mathrm{paper}}[\%]
=100\frac{F_{\mathrm{VBA}}-F_{\mathrm{eSPFEM}}}{F_{\mathrm{eSPFEM}}}.
\]

符号付き差と絶対値を区別する。SRMの区間を持つ場合は、単一の代表値だけでなく区間両端も記録する。

**eSPFEMの値は解析解や唯一の正解ではない。** 表の手法間の最小値～最大値を、そのまま合格許容範囲にしない。表のLB・UBも、材料・流れ則・離散化の対応を確認せずに、当該VBAの保証された上下界として使わない。

高速化の回帰判定はまず同一条件のVBA Baselineとの比較で行い、論文との差はモデル妥当性の評価として別に扱う。

## 10. 変形・破壊機構の照合点

### 10.1 原論文の定性的な結果 [P：p.9、Figure 4と本文]

同じcでφが大きくなると、潜在的な破壊土塊の大きさが小さくなると説明されている。Case1とCase3の比較では、cが大きいCase3の方が破壊面が深くなると説明されている。

この傾向は、境界条件・材料入力・塑性域に不自然な変化がないかを確認する補助情報に使う。[V] すべり面をあらかじめ円弧に固定したり、Figure 4と完全に同じ色分布になることを強制したりしない。積分点の塑性ひずみ、相当塑性ひずみ、せん断ひずみは、定義を合わせて比較する。

### 10.2 Case2の注意点 [P：p.9～10、Figures 5・6]

論文はCase2について、SRF<1.30では変位が収束し、SRF≥1.30では初期の小変形段階で収束せず、その後の大変形段階で崩壊した土塊が再び安定する挙動を説明している。

したがってVBAでは、**崩壊後に変位の増加が止まったことと、元の斜面の初期安定性を区別する。** また、論文が1.30と報告していることを理由に、VBAのF=1.30を強制的にFAILにしない。メッシュ・構成則・判定法の差を踏まえ、残差、塑性域、変位、到達載荷率を保存して評価する。[V]

## 11. 高速化比較の試験条件 [V：以下は論文の指定値ではない]

### 11.1 固定F試験とSRM全探索を分ける

**固定F試験**では、同じF、同じ開始状態、同じメッシュ、同じ収束・終了判定で、予測子、接線再利用、LU再利用などの影響を比較する。

**SRM全探索試験**では、同じ探索開始条件・終了精度で、試行したFの順序を含む総費用を比較する。探索法の変更による短縮と、固定Fのソルバー改善による短縮を混同しない。

### 11.2 固定Fの試験候補

下表の値は、本条件書で選ぶ検証点である。論文が各点のPASS/FAILを網羅しているわけではない。初回は低めの確認点から始め、近限界点と高めの点へ広げる。

| Case | 低めの確認点 | 近限界付近の候補 | 高めの確認点 |
|---|---|---|---|
| Case1 | 0.50, 0.60 | 0.65, 0.68, 0.70 | 0.75, 1.00 |
| Case2 | 1.10, 1.20 | 1.28, 1.30, 1.32, 1.36 | 1.40 |
| Case3 | 0.90, 1.10 | 1.16, 1.18, 1.20 | 1.25 |
| Case4 | 2.00, 2.20 | 2.25, 2.2625, 2.27, 2.275 | 2.30 |

「低め」は安全を保証するラベルではない。全点を実際に解いて状態を記録する。Case4の2.2625・2.275は細かい比較のための追加試験点であり、Table 1の報告値ではない。

### 11.3 新規の共通SRM探索設定案

既存Baselineの設定を維持する回帰試験では、既存値を優先して記録する。以下を採用するときはBaselineにも同じ設定を用い、再計算する。

| 項目 | 新規試験の設定案 |
|---|---|
| 初回試行F | 0.50、全Case共通 |
| 初期探索の増分 | 0.10 |
| 初期探索の上側上限 | 3.00 |
| 下側の探索 | 0.50で開始できなければF>0の範囲で下側へ探索。入力エラーは除外して扱う |
| 探索区間形成後の基準法 | 二分法 |
| 初回の探索終了幅 | F_upper−F_lower ≤ 0.02 |
| 精度確認用の別試験 | 全比較版を同じ条件で幅≤0.005まで計算 |
| Newton・線形求解の許容値 | Baselineから取得して固定。論文からは設定できない |
| 最大反復・cutback・最小載荷刻み | Baselineから取得して固定 |

0.02は絶対幅であり、全Case共通の相対誤差2%や1%を意味しない。例えば0.02/0.68は約2.94%である。必要な精度と探索幅は区別して指定する。

上限到達時に区間を形成できなければ「探索範囲不足」とし、上限値を安全率として返さない。早期中断・タイムアウトだけで失敗側の端点を更新しない。

### 11.4 数値状態と力学的評価を分離する

| 保存する状態 | 意味 |
|---|---|
| CONVERGED | 指定した目標荷重まで到達し、基準の数値収束条件を満たした |
| NOT_CONVERGED | 規定の反復・cutback等で、基準の収束条件を満たせなかった |
| INVALID_INPUT | 材料・拘束・メッシュ等の入力が不正 |
| UNDETERMINED | 時間打切り、手動中断、パイロット終了等で判定未完了 |

力学的な限界状態の指標は別欄へ記録する。`NOT_CONVERGED`は、それだけで数学的に証明された斜面崩壊や厳密な安全率上界を意味しない。

高速化版だけ反復上限を削る、許容残差を緩める、変位閾値で早く打ち切る、監視だけだった指標をFAIL判定へ昇格する、といった変更は、同一判定条件の高速化試験に混ぜない。

### 11.5 時間計測と精度確認

同一PC、同一Excel版・bit数、同じ出力頻度で測定する。主タイマーは「入力読込み後、初期化開始から固定FまたはSRM探索終了まで」とし、メッシュ生成・結果描画・ファイル出力は別計測にする。4ケースの読込みや材料変更時に残るキャッシュも、比較条件を揃える。

可能なら各条件3回を測定して中央値を報告し、最低値だけを使わない。計算負担から1回だけの場合は、そのことを明記する。

```text
固定Fの速度倍率  = Baselineの同一F実行時間 / 高速化版の同一F実行時間
SRMの速度倍率    = BaselineのSRM総時間 / 高速化版のSRM総時間
4Case合計倍率    = ΣBaselineの各Case時間 / Σ高速化版の各Case時間
```

回帰確認では、Fs区間とその実幅、目標載荷率への到達、残差、材料更新の健全性、点Aの変位、塑性域を比較する。許容幅を満たしたかだけでなく、実際の区間幅も報告する。

Baselineと異なる近限界Fで収束した場合は、直ちに採用または棄却せず、同じFでの再解析、刻みを細かくした解析などで原因を確認する。論文との差の許容率や変位の許容差は論文からは定められないため、プロジェクト側の判定値として事前に明文化する。

## 14. 実装・試験開始前に確定する項目

### 14.1 論文だけでは決められない項目

対象資料だけでは、現行VBAのシート列との対応、Q4の積分法、材料の稜線・頂点処理や引張カット、正則化、厳密な流れ則実装、初期応力生成法、K0、各F間の履歴受渡し、Newton・線形求解の許容値、cutback条件、SRM探索幅、同一メッシュの全接続までは確定できない。

これらは「論文値」として補完せず、Baselineの設定または明示的な[V]設定として保存する。設定変更を行う場合には、比較対象側も同条件で再計算する。

### 14.2 最小の確認順序

1. Figure 3の座標・拘束を入力し、面積158 m²、自重3160 kN（奥行1 m）、法肩A=(10,10)を確認する。
2. 全Caseで共通のメッシュと数値条件を固定し、c・φだけを切り替える。
3. 第6.2節の低減値と、F<1を受け付けることを確認する。
4. 各Caseの低めの固定Fを実行して入力・残差・反力・材料更新を確認する。
5. 近限界点・高めの固定Fを含むBaselineを記録する。
6. 同じ条件で高速化版を実行し、最後にSRM全探索の総時間と精度を比較する。

**最優先の取り違え防止事項：斜面比高は6 m、Eは14,000 kPa、ψは0°、Case1はF<1も探索、Case1～4は同じ均質斜面でc・φだけを変更する。**
