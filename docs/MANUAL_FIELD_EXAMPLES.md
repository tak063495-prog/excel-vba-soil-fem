## R58-02：監視点の有効性

- 道路は全11工程で存続する節点19（4,0 m）へ変更。工程4/6/11の追加沈下は4.861／3.705／11.386 mm。節点20は工程6〜8で有効接続0のため連続沈下として使わない。
- トンネル天端330は工程3〜4、下端114は工程7〜8で接続0。高さ方向の曲線を切り、有効区間1〜2、5〜6、9の先頭を基準にした。工程2は基準1から18.1837 mm、工程6は基準5から4.3650 mm。最終9の0は新基準の開始。
- 左右438/222と地表351は全工程で有効。幅−1.6918 mmと地表追加沈下5.6898 mmは工程1との差。従来の高さ23.7871 mmは「無効期間をまたぐモデル自由度差」と定義し、連続内面測点の閉合とは区別する。
- 初期材料・施工操作から有効集合を再生し、各工程の結果要素IDとの完全一致を確認。監視点の接続数も同集合から再集計した。[元記録SHA256・全工程値](manual-field-evidence/20261024/field_examples.json)。

PDFの図は旧合格記録の再集計を保持。今回の最新版操作確認値とは分離した。最新版の道路Y変位は旧値と一致。トンネル地表追加沈下は旧5.689765 mm／今回5.694450 mm、全節点最大Y変位差0.101353 mmで、異版間の数値完全一致とは報告しない。
