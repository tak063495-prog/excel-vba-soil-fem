# SRM凡例の追加訂正

PR29後の再レビュー指摘に対応し、FEMIoのステージ凡例・空ステージ既定説明・仕様シートの3文言を「最後の有効行のSRM」に統一しました。計算処理とPDF（p.34）は変更していません。

- GRAVITY → SRM → LOAD（すべて有効）：SRMは途中ゲート。
- GRAVITY → SRM → LOAD（LOADは無効）：SRMは最後の有効行なのでFs探索。

「最後に現れるSRM」という意味ではありません。FEMEngineの`P3HasStageAfter`は、後続の有効ステージがあるかを種別に関係なく調べています。

専用コピーで汎用101項目・道路102項目を実Excelで確認しました。VBEコンパイル、凡例と仕様の再生成、保存・再読込、空ステージ生成、旧N01のゼロDISP凡例と載荷入力規則も確認。汎用の既存8表・道路の既存9入力/結果表は更新前と完全一致です。埋込モジュールはFEMIoのみ更新し、他モジュールは保存前後で照合しました。今回は解析を再実行していません。

汎用原版と道路実習ZIPの名称UI_05・ファイル名を維持して訂正し、配布SHAを更新しています。DLL、Double、材料則、収束条件、SRM探索処理は変更していません。旧UI_04の履歴ZIPは保持しています。

検証記録は`docs/manuals/construction-evidence/20261021/srm-legend/`の`generic_checks.json`、`road_checks.json`。再現用は`tests/verify_manual_rereview.ps1`（今回の文言確認には`-RunRoad`を付けません）。以前の94/143項目の記録は当時の履歴として保持し、今回の101/102項目とは区別します。
