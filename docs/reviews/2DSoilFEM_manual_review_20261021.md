# 2D Soil FEM 説明書レビュー

2026年10月21日 初回レビュー

## 結論

本書は、実画面、施工例、支持力、SRM、流れ則、結果の解釈と適用限界をかなり丁寧にまとめています。特に「数値収束と物理破壊は別」「SRM後の変位は通常時の変位予測ではない」「STRUCTは自動的に弾性体にならない」といった注意は明確です。

一方、初見の利用者が説明書だけを順に読み、入力して計算を再現し、別の地形・材料・荷重へ変更するためには、次の補強が必要です。

1. **説明書と配布Excelの食い違いを先に解消する。** 節点番号を入力する手順と入力規則が一致せず、DISP=0の説明は画面側で逆になっています。
2. **最初の一件を最後まで完走する導線を作る。** 入手するZIP、開くファイル、入力の入替え、期待結果、保存・再表示を一つの手順にまとめる必要があります。
3. **応用時に変わるものを具体化する。** 外側境界の行順と材料番号の関係、旧入力の消去、再生成後の節点番号、荷重合力、自重基準値の取り直しが重要です。
4. **「確認する」だけでなく、確認方法と小さな検算を載せる。** 既存例に手計算と一条件だけ変える演習を加えると、単なる模倣から理解を伴う応用へ進めます。

総合すると、**技術解説・検証資料としては充実していますが、初心者が単独で再現して応用する実習マニュアルとしては、入口と操作のつなぎに不足があります。** 以下は机上レビューであり、初心者による実機ユーザーテストの結果ではありません。

## 1 優先して直したい項目

### R01 節点番号を入力する手順と入力規則が一致しない

**P1・確定不整合／p.19、p.62、p.69–70**

p.19は載荷B列の選択方法に「節点番号」を含め、p.70は39、46、44などの番号を使う具体例です。しかし、配布XLSMの「載荷」B2:B2000の入力規則は `TOP,BOTTOM,LEFT,RIGHT,BOX` のリストだけです。保存XMLはエラー表示有効、UI生成コードも停止型の `xlValidAlertStop` を指定しています。計算側は数値の節点番号に対応しています。

**影響：** 説明書に従って番号を直接入力する初心者が、入力段階で拒否される設定です。自動入力で作成済みの例を開けることと、同じ表を手で作れることは別です。実Excelで拒否ダイアログを再現したという意味ではありません。

**改善案：** UIの入力規則を「5キーワード、または有効な正の整数節点番号」に合わせてください。修正後はp.70の9行を通常の手入力で登録できるか確認する必要があります。貼付けによる入力規則の回避を正規手順にはしない方がよいです。

根拠：[UI規則の作成](https://github.com/tak063495-prog/excel-vba-soil-fem/blob/298599a6643b3f98a1b070936da6459af85611df/src/vba/FEMUiLayout.bas#L105-L110)、[載荷B列の選択肢](https://github.com/tak063495-prog/excel-vba-soil-fem/blob/298599a6643b3f98a1b070936da6459af85611df/src/vba/FEMUiLayout.bas#L173-L176)、[番号を受理する計算側](https://github.com/tak063495-prog/excel-vba-soil-fem/blob/298599a6643b3f98a1b070936da6459af85611df/src/vba/FEMEngine.bas#L3496-L3506)。

### R02 DISP=0の説明がPDFと配布画面で逆になっている

**P1・確定不整合／p.19**

PDFは正しく「DISP=0もゼロ変位拘束」と説明しています。一方、配布ブックの「載荷」M12は「DISP/FORCEはその行を無効。FIXは0でも拘束」です。同じ古い説明が凡例・仕様生成コードにも残っています。実装はDISP=0でも拘束を設定します。

**影響：** 荷重行を無効にしたつもりで、節点を0変位に固定してしまいます。沈下、反力、安定性を変えるため、説明上の小さな問題ではありません。

**改善案：** PDFの記述に画面・凡例・仕様を統一してください。「DISP=0は無効化ではない」「無効化は該当LOAD工程を無効にする等」を主要警告として示すとよいです。

根拠：[古い凡例](https://github.com/tak063495-prog/excel-vba-soil-fem/blob/298599a6643b3f98a1b070936da6459af85611df/src/vba/FEMIo.bas#L3517-L3518)、[仕様にも残る説明](https://github.com/tak063495-prog/excel-vba-soil-fem/blob/298599a6643b3f98a1b070936da6459af85611df/src/vba/FEMIo.bas#L3770-L3772)、[実際の拘束処理](https://github.com/tak063495-prog/excel-vba-soil-fem/blob/298599a6643b3f98a1b070936da6459af85611df/src/vba/FEMEngine.bas#L3707-L3715)。

### R03 形状領域と材料番号の割当規則が不足している

**P1・説明不足と設定説明の不正確さ／p.14、p.42–45、p.90–91**

「要素J列を照合」は書かれていますが、生成時に何が材料番号を決めるかが説明されていません。現行の形状入力処理はG列の境界番号を読まず、H/I/Jを上から読みます。外側境界の出現順を内部の領域番号とし、通常は、その領域に入る要素へその番号を材料番号として付けます。要素中心の判定にどの外側領域も一致しない場合にMESH_MATERIALを使います。

**影響：** G列の番号だけを変更しても材料は変わりません。一方、外側境界の行を並べ替えると材料割当が変わり得ます。道路例は境界番号と行順が一致しているため、そのまま写す場合には気づかず、領域追加や材料変更で誤るおそれがあります。C9だけで全領域へ任意材料を割り当てられるようにも読めます。

**改善案：** 「G列の番号／外側境界の行順／生成材料番号／要素J列」の対応を2材料の小例で明示してください。要素J列を編集する場合の選択・確認方法、生成し直すと割当を再確認することも記載してください。

根拠：[形状入力の読取り](https://github.com/tak063495-prog/excel-vba-soil-fem/blob/298599a6643b3f98a1b070936da6459af85611df/src/vba/FEMUiGeometry.bas#L31-L64)、[外側境界を順序で配置](https://github.com/tak063495-prog/excel-vba-soil-fem/blob/298599a6643b3f98a1b070936da6459af85611df/src/vba/FEMUiGeometry.bas#L100-L107)、[材料判定](https://github.com/tak063495-prog/excel-vba-soil-fem/blob/298599a6643b3f98a1b070936da6459af85611df/src/vba/Mesh.bas#L2808-L2868)。

### R04 新しいケースへ切り替えるときの旧入力の消去が必要

**P1・説明不足／p.9、p.14、p.20、p.42–45**

元ブックをコピーすることやケースを混ぜない注意はありますが、「短い表を古い表の先頭へ上書きしても末尾は残る」ことと消去範囲が説明されていません。読取り処理は最終データ行まで進むため、残った材料、形状、載荷、E列が有効の施工工程を新ケースへ混ぜる危険があります。

**改善案：** 新規作成用の専用手順を置いてください。

1. 別名コピーを作る。
2. 見出し・凡例・入力規則を残し、既存データ範囲の内容だけを消す。
3. 新しい材料・形状または保存節点/要素を入力する。
4. 不要な載荷・接合・後続工程を消去または無効化する。
5. 材料数、節点数、要素数、有効工程数、最後のデータ行を照合する。

形状から生成するルートと、保存メッシュをそのまま使うルートは分けるべきです。実際に旧行を混ぜた計算を今回実行したわけではありません。

根拠：[節点の最終行読取り](https://github.com/tak063495-prog/excel-vba-soil-fem/blob/298599a6643b3f98a1b070936da6459af85611df/src/vba/FEM.bas#L239-L244)、[材料読取り](https://github.com/tak063495-prog/excel-vba-soil-fem/blob/298599a6643b3f98a1b070936da6459af85611df/src/vba/FEM.bas#L281-L286)、[施工行読取り](https://github.com/tak063495-prog/excel-vba-soil-fem/blob/298599a6643b3f98a1b070936da6459af85611df/src/vba/FEMEngine.bas#L3294-L3324)。

### R06 トンネルの掘削径と土被りの呼び方を整合させる

**P2・確定した寸法用語の不整合／p.64、p.67**

p.64は「土被り20m、掘削径8m、支保厚0.3m、中心(0,-24)m」です。一方、p.67と保存入力では内空半径4.0m、支保外周半径4.3mです。支保占有域も掘削して置き換えるモデルなので、幾何学的には次の対応です。

- 内空径：8.0m
- 支保外径、掘削する領域の外径：8.6m

**改善案：** 寸法入り断面図を一枚入れ、「20mはどこまでの距離か」「8mは内空径か掘削径か」を統一してください。p.64–67の条件票にはFLOW_POLICY=INCONSISTENTも明記すると、前の擁壁DAVIS設定を残す誤操作を防げます。

## 5 追加すると有効な計算例と演習

既に支持力と擁壁断面力の実例は載っています。「計算例がない」と一括して指摘するのは適切ではありません。追加の優先順位は、未掲載機能を増やすことだけでなく、既存例を自分で検算・変更できるようにすることです。

### A 既存の水平地盤例に手計算を付ける

**最初の検算に推奨／p.68–70**

水平地盤の高さは5−(−12)=17m。γ=18kN/m³、E=30000kPa、ν=0.3です。横ひずみを拘束する一様な弾性自重状態では、拘束弾性係数と地表沈下は次のようになります。

- M = E(1−ν) / ((1+ν)(1−2ν)) = 40384.615kPa
- s = γH² / (2M) = 0.064405714m = 64.405714mm
- Y正が上なので、uy0 = −0.064405714m

これはp.70の自重後基準値と一致します。**今回の新規FEM解析値ではなく、本文条件による独立な手計算です。** この式が成り立つ一様断面・拘束・弾性の仮定を併記し、斜面へそのまま流用しないと説明してください。

### B 道路例で単位体積重量だけを変更する

**類似例への最初の演習に推奨／p.42–46**

材料8のγだけ19→20kN/m³に変え、他条件は固定する例です。工程11ではMATSETされた領域3・6と領域8が対象で、面積は8＋8＋6=22m²、奥行1mです。

- 期待する追加自重：22×1×1=22kN
- 工程11の鉛直支持反力：元の1842kNから約1864kNになるという釣合い予測
- 工程1は材料8の影響を受けず、元の1440kNのまま

**1864kNは理論上の釣合い予測で、今回再解析して得た値ではありません。** 実計算では残差も確認します。この演習で、MATSETのコピー元、奥行、単位、工程別結果、反力検算をまとめて学べます。

### C 面圧からQ8辺の節点力へ換算する数値例

**式だけでなく載荷表まで追加／p.19、p.73**

p.73には正しい換算式があります。例えば一様面圧p=10kPa、直線辺L=1m、奥行t=1mなら、下向きの節点力は端点各−1.666667kN、中点−6.666667kN、合計−10kNです。隣接辺の共有端点では寄与を合算します。

載荷A:Eへどの節点番号を何行入れるか、粗密化しても合力を保つには何を変えるかまで示すと、FORCEを応用しやすくなります。これは例示の算術換算で、掲載の16ケースを荷重制御で再解析した結果ではありません。

### D 同じモデルで境界距離とメッシュを一つずつ変える

**応用判断に重要／p.15–16、p.36–37、p.53、p.73、p.90**

「十分遠く」「粗密比較」は書かれていますが、初見の利用者が何を固定し何を比較するかを決める例が不足しています。

- 境界だけ遠ざけ、材料・載荷幅・近傍メッシュを固定して変位、反力、Fsを比較。
- 評価座標を固定し、粗・中・細で同じ量を比較。
- 節点力では合力を維持し、DISPでは自重基準を取り直す。
- 隅角ピーク、特異点、異なる最終Fsでの変位を同じ精度指標に混ぜない。

全案件共通の許容差を安易に置くのではなく、目的と事前に決めた評価量に対する感度として説明するのが適切です。

### E JOINTの最小計算例

**未掲載の機能例として優先／p.4、p.22**

模式図と入力説明はありますが、圧縮・開口・すべりの状態が変わる一連の数値例がありません。二つのブロックと一つの接合で、材料A/B、Kn/Ks、引張許容、接合挿入後の節点、3積分点の結果を照合する例が有効です。履歴なしモデルなので、累積塑性すべりや除荷剛性を検証した例とはしないでください。

### F LOAD/UNLOADとRESETの小比較

**操作を取り違えやすい部分／p.19–22、p.4、p.108**

同じ小モデルで、力載荷、指定変位、FIX、UNLOAD、RESET_U、RESET_STRESSの差を一つずつ比べる例を推奨します。特に「UNLOADは載荷指定を外す」「RESETは履歴を消す」「沈下表示の差分を取る」は別操作であることを、残る量・消える量で示してください。

## 7 改訂の進め方

1. **先に配布UIとの矛盾を修正。** R01、R02を最優先にし、通常の手入力で支持力例が登録できることを確認する。
2. **初回実習を一本化。** 道路例のZIP取得から、旧入力を残さず設定し、328節点・95要素・11工程を確認し、工程11の反力1842kN等を照合して、保存・再表示までを連続した手順にする。
3. **応用時の規則を追加。** R03、R04、WARN判断、荷重合力、DISP基準を一か所に集め、一条件変更の演習を付ける。
4. **本文・画面・READMEを同時に照合。** トンネル寸法、アンカー工程、表紙の由来、DLL個数、旧版リンクを修正する。
5. **次に未掲載の最小例を追加。** JOINT、LOAD/UNLOAD、RESET、境界距離・メッシュ感度の順で、入力・操作・期待値・限界をセットにする。

改訂後の確認では、「説明が増えたか」だけでなく、説明書を初めて見た人が、質問なしで一例を完走し、材料または荷重を一つ変更して結果の変化を説明できるかを合格目標にすると有効です。
