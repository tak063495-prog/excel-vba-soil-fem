# PDF説明書の整合修正と水理の解析例14～18（2026-10-23）

## WATERの指定順

8.5節と28章の工程早見表を、工程別入力表および `GWResolveStageProfile` / `GWValidateStagePlans` の仕様にそろえました。順は「水条件」N列（L列で工程IDが一致）→「ステージ」C列→「水条件」B5です。N/Cを両方指定する場合は同一IDとし、矛盾は停止します。「Cが空欄なら常にB5」という省略を残さないようにしました。

## 現行メッシュ生成と旧例題

4章でC29=0/1/2、初期値1、方式2内部の形状別経路、不適用時の停止を整理しました。旧C29=2は候補比較後の地形格子優先で、現行C29=2はデローニ・33候補比較を省く直接生成です。同じ形状・間隔・番号でも同じメッシュになる保証はありません。

72要素・261節点と330要素・1065節点は旧保存例の値として保持しました。保存メッシュを使う再現手順と、現行方式で再生成して新たに検証する手順を分けています。該当保存ブックへの直接リンク、粘着力20 kPaの解析例1と10 kPaの基準例の違い、番号依存条件の再設定も記載しました。関連する地形格子ガイドの「自動選択」は、C29=2の内部の選択に限定しました。

## 水理画面の出典

図4-5-A/Dはcutoff（STEADY、左5 m・右4 m）、Bはone_way（工程2へV=4 m）、Cはfixed13（HYDROSTATIC、幅20 m・高さ10 m、水位1 m）と明記しました。CとDを同一モデルでモードだけ変えた比較と読ませないようにしました。[画像・入力・実画面記録との対応](../manuals/water_screen_sources.json)を保存しています。

## 解析例の並びと入力欄の誘導

第8章は水理の共通入力・理論・出力とし、既存の解析例1～13の後ろに解析例14～18を追加しました。14は折れ線指定水位、15は遮水体下の定常浸透、16は空洞内外の静水圧・浮力、17はWATER施工と湿潤斜面SRM、18はJOINT水圧です。旧入力一覧・結果・エラー・付録は28～31章へ移り、用語集は巻末です。旧章の内容を新機能のために書き換えず、章節・図・ページ参照を更新しています。

赤枠はExcelの入力UIに追加したものではなく、説明書の実画面で編集箇所へ視線を誘導する注記です。共通B3:B6、水位線A:D、材料水理特性F:I、境界表A:F、工程別L:Nと空欄O:S、施工A:F、接合F:Gを囲み、本文と番号を対応させました。元スクリーンショットは保持し、`tests/annotate_water_manual.py`で注記画像を再生成できます。

## 折れ線水位の実計算

配布原版の専用コピーで、幅20 m・85節点・20 Q8要素の斜面にW=(0,3),(8,3),(14,1.5),(20,1.5)を入力しました。HYDROSTATIC・INCONSISTENT・固定Fs=1.0、自重→SRMの2工程です。指定折れ線を線形補間した水圧を使う入力例で、自由水面や浸透流を解いた結果とは記載しません。

実測は5.2993111 s、最大節点変位ノルム0.073437091565 m、相対残差5.484856e-15、自重/鉛直反力3160 kN。全160GP行の水圧補間式との差0 kPa（出力座標の精度内）、全応力−有効応力−pの最大差1.066e-14 kPa、保存再開の全170DOF変位差4.990e-13 mを確認しました。計算済みブック・単一DLL・再現入力・全数値表・実行/再開ログは[例題ZIP](../manuals/examples/water_polyline_example.zip)と[検算記録](../water-display-evidence/20261023/polyline/checks.json)へ保存しました。比較速度試験やFs区間探索ではありません。

専用コピーの入力・水圧プレビュー・保存結果復元・応力図を実Excel画面で確認しました。プレビュー後に直接応力図へ進むと「解析成功後に結果表示してください」の保護により止まったため、水圧結果で保存状態を復元してから応力図を表示する手順に修正し、その順で表示できることを確認しました。実行環境はExcel16.0 build20430であり、Excel2016永続版実機の再試験とは記載していません。

## 説明書用変位図の節点対応

PDF後処理の`plot_water_srm.py`が、RCM並べ替え後の内部TDisp配列を入力節点順とみなしていました。保存「結果節点」の最終工程の節点番号・座標・ux/uyを使用し、fixture座標・固定変位を照合するよう修正しました。旧8-8/9/10（現在の図17-3/4/5）を同じ保存数値から再描画しました。固定Fs=1.3図は変形倍率1、SRM探索2図は参照形状への変位着色です。Excelの計算値・全体最大変位・Fs・残差は変更していません。節点表が無い場合は順序を推測せずエラーにします。
