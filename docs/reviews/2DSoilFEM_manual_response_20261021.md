- UI_05候補の実Excelで38項目を確認：入力規則とSTOP属性、5キーワード・9節点ID、無効値、VBE全体コンパイル、設定数式の危険な再配置の変更前停止と全シート値/式の非変更、保存再読込、埋込6モジュールとソースの一致。
- 道路の元条件（材料8 γ=19）とγだけ20へ変更した2条件を修正版で計算。各11工程の入力表・全節点変位/力/反力・全積分点応力/ひずみ・ステージ結果は修正前の対応ケースと完全一致。材料則・倍精度・収束/SRM条件は緩めていません。
- γ変更は追加自重22kNという面積検算と一致し、工程1反力1440kNは不変、工程11反力は1842→1864kN。独立な全鉛直釣合い差は約2.56e-13kN。
- 水平地盤の一様弾性自重の独立手計算は沈下64.405714mm。斜面へそのまま流用しない仮定を併記。
- 道路の計算済みUI_05コピーを保存・閉じる・開き直す・再描画する一往復を確認。既存図を削除してから新しいSVG形状が生成されること、3結果表が変わらないことを確認。
- 保存済み擁壁wall_davis08の同一Fs=1.7のA/Bを実Excelで再描画。塑性クロスの色/矢印を修正しました。保存された全/塑性ひずみ増分は圧縮正であり、正=青/内向き、負=赤/外向きです。計算の再実行ではありません。

## Issue #26・#27と未実施事項

Issue #26は、観測用の増分保存で、材料更新を省略するゼロ局所変位の条件に合わせて塑性増分を0とする修正です。材料の応力・降伏・接線/累積履歴を消していません。合成された観測テストではゼロ/非ゼロ閾値、材料配列の非変更、スナップショット、圧縮正の成分・色・矢印を確認しました。**DLL/VBA・FINAL/ALLを組み合わせた実塑性保持工程と全SRM探索を今回すべて再実行したわけではありません。** Issueの回帰案を全面完了したとは扱いません。

Issue #27は、数式の一般的な参照書換えを実装したものではありません。高速化設定のキーが予定位置から動いておりブック内に数式が存在する場合、再構築前に停止します。標準配置での数式は保持し、行挿入後は入力を破壊せず拒否することを確認しました。無関係の数式でも安全側に停止し得ます。開いていない他ブックの外部参照の自動保全は対象外です。

入力規則の検証は実Excelの`Validation.Value`と停止属性によるプログラム検査で、初心者がキーボードで9行を入力して拒否ダイアログまで確認したユーザーテストではありません。JOINTの開閉・すべり、LOAD/UNLOAD・RESETの新規実計算、境界距離を変えた感度試験は追加していません。意味と制約を補い、実行していない例を実計算済みと表示しない方針です。擁壁曲げの精度未確認という既存の制限も維持しています。
