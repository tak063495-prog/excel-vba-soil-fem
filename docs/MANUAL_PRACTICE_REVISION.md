## 増強した実務での整理

- 道路拡幅：切土範囲・別材料再盛土の材料番号、土量と工程別反力・変位、天端を1 m高くした実計算比較図。重量増分57 kN/mと反力増分が一致。
- 擁壁背面盛土：通常施工完了Fs=1のN/V/Mと地盤SRMを別の成果物に整理。壁体自重、断面位置、力・モーメントの釣合いを対応付けた。
- トンネル：上下半と支保占有域の区分、DEATH/MATSET/BIRTHの順序、対向点の相対変位、通常施工と最終SRMの結果の使い分け。
- アンカー相当力：奥行当たりへの換算、等大反対向きの合力、緊張前後の相対変位と地盤SRM。
- 支持力：自重後の追加沈下と載荷帯反力、50 mm沈下の細メッシュ水平／斜面の保存計算値、荷重―沈下曲線・機構・粗密比較。
- 時間連成：盛土直後・放置後の沈下／水圧／必要Fsの整理表、施工時間・排水面・透水性を変える入力箇所と比較対象。基準の実計算値と、条件を変更するための手順を区別。

出典は原稿の各例のリンクと [PDF検査記録](manual-practice-evidence/20261024/checks.json) に記録した。既存例の確認値表131行を例番号単位で照合し、内容を保持した。

## 検査の再現

```powershell
python -X utf8 tests/build_manual_practice_figures.py
$env:MANUAL_PUBLIC_REF='main'
$env:MANUAL_PDF_TITLE='2DSoilFEM 操作説明書 20261024'
python -X utf8 docs/manuals/build_manual_pdf_v2.py docs/manuals/2DSoilFEM_Manual_20261024.md docs/manuals/2DSoilFEM_Manual_20261024.pdf
python -X utf8 tests/check_manual_practice_inputs.py
python -X utf8 tests/check_manual24_coverage.py
python -X utf8 tests/check_manual24_pdf.py --ref INDEX
python -X utf8 tests/review_manual_practice.py
```

全ページをPopplerで画像化し、一覧と主要ページの拡大画像を目視する。目次・しおりの章開始ページ、図番号、外部リンク、ページ外文字、白紙、孤立見出しも確認する。PDF内のリポジトリへのリンクはmainに統一している。

最終確認：241ページ・37章・図キャプション218件・mainファイルリンク32件。白紙、ページ外文字、孤立見出し、ローカルファイルリンクは0。旧確認値表131行と従来の解析例画像を保持した。全ページを13枚の一覧で確認し、主要12ページを拡大確認。最終の表記調整3ページを再確認し、残る238ページは確認済み画像と画素一致した。[入力参照](manual-practice-evidence/20261024/input_routes.json)、[従来値保持](manual-practice-evidence/20261024/coverage.json)、[組版・リンク](manual-practice-evidence/20261024/pdf_link_bounds_checks.json)、[画像記録](manual-practice-evidence/20261024/visual_review.zip)、[配布同一性](manual-practice-evidence/20261024/package.json)。
