# 未使用節点と任意節点番号の入力設計

本書は、実務で座標を先に多数登録し、材料領域や要素構成を後から追加する作業を可能にする設計案である。登録データを削除せず、参照される節点だけを解析へ渡し、利用者の番号と内部番号を分離する。入力照査の厳密さ、材料則、収束条件、既存の施工履歴・保存再開の安全性は維持する。

**文書のみの提案であり、以下の機能を今回実装したものではない。** VBA・DLL・XLSM・PDFを変更せず、独立したExcel/VBA実行も行っていない。試験表は将来の受入条件であり、実行済み結果ではない。

## 1 対象と現状

確認基準は main `6a9ad0c5bec98a3012d71a18e91f33f6cfab9c9e` と、そこで公開される `2DSoilFEM_ui_20261024.xlsm` に対応するソースである。ブック内VBAを独立抽出して同一性を検証したわけではない。

「入力節点」「材料構成」が形状定義を指すか、生成後の直接FEM入力を指すかで改修範囲が異なるため、二つの経路を分離する。形状入力だけの変更をもって直接FEM入力も対応済みとはしない。

| 経路 | 現行仕様 | 本書の段階 |
|---|---|---|
| モデルの形状座標と材料領域・穴 | 外部IDは正整数1～60000。飛び番・1以外開始に既に対応。境界で未使用の座標は拒否 | Phase A |
| 節点データ・要素データの直接入力 | 1開始連番・行順一致が必要。未接続節点を拒否 | Phase B |

UI24の「形状の座標」は「形状入力」B8:D2000、「形状の領域」はG8:J2000へ接続する。生成済み節点の支持・変位を扱う「節点データ」は別の表である。座標読取ルーチンの上限とUI表示・編集範囲は同一とは限らず、実装前に両者を照合する。

## 2 共通の設計契約

1. **登録点台帳を正本とする。** 未使用という理由だけで行・番号・座標を削除しない。入力IDは利用者が管理し、内部の配列添字として直接使用しない。
2. **登録と使用を分ける。** 使用集合をモデルの接続・領域から導出し、登録点には使用中／未使用を表示する。手入力の使用フラグと接続関係を二重の正本にしない。
3. **最大IDではなく使用数に比例して確保する。** 辞書による外部IDから内部添字への対応と、逆引き配列を持つ。
4. **未使用はゼロ解ではない。** 出力する場合は「解析対象外」とし、変位・水圧・反力0の計算結果を作らない。
5. **無効な参照は停止する。** 未定義ID、重複ID、使用点の不正座標、不正な境界・要素は従来どおりエラーとする。
6. **全工程のモデル定義を保持する。** 初期OFFでも後でBIRTHする要素・領域を、初期工程だけの活性判定で削除しない。工程ごとの自由度活性化は既存の施工処理に任せる。
7. **元のデータを壊さない。** 全入力・対応表・出力候補を検査してから適用する。適用途中の失敗・中断時には以前の有効入力と関連状態を復元する。復元を保証できない状態を解析可能と表示しない。

最初の実装では、未使用点にもIDの正整数・一意性とX/Yの入力形式を要求する。完全空白行は無視できるが、IDだけの未完成行を受理する「下書き機能」は別仕様とする。未使用点許容と不正入力許容を混同しない。

## 3 Phase A 形状入力の未使用点を許容する

### 3.1 使用集合と番号順

`coords` は登録点台帳として保持し、外側境界・材料領域・穴の境界に出現するIDの和集合を `allSeen` とする。使用点数は `usedCount = allSeen.Count`、未使用は `coords.Keys − allSeen.Keys` で求める。

内部番号は現行と同じ「外側境界での初出順、次に内側境界での初出順」を維持する。座標表の行順やIDの大小で並べ替えない。これにより、境界の順序・使用座標が同じなら、未使用点の追加・削除・移動だけで内部番号やメッシュを変えない。

例：登録IDが101、205、310、900で、境界が101→310→900なら、内部対応は101→1、310→2、900→3となる。205は台帳に残り、図形定義やメッシュ生成には入らない。後で境界へ205を追加すれば使用点へ昇格する。

外側と内側の不正共有、同じ境界内のID重複、自己交差等の現行検査は保持する。同じ座標でも別IDなら自動結合せず、幾何学的妥当性は既存規則で検査する。未使用点を、領域内にあるという理由だけで自動挿入しない。

### 3.2 必要な変更箇所

中心は `FEMUiGeometry.bas` の `FEMUiBuildGeometry` である。

- L67–68の未使用点停止を、未使用ID・元行の一覧作成へ置換する。外側／内側共有の検査は残す。
- L71の `pointData` 確保、L92の出力範囲、L95の座標総数を、すべて `coords.Count` から `usedCount` へ揃える。
- 出力前に `nativeIds.Count = usedCount`、付番数一致、境界全IDの対応表存在、使用点数の許容範囲を検査する。
- 使用座標・領域だけを従来の「図形定義」へ渡す。メッシャやソルバーの入力スキーマは変えない。
- 登録数・使用数・未使用数・対応表を確認画面または診断表へ表示する。警告で計算を毎回中断せず、未使用があることを見落とさない表示とする。
- 既存のイベント復元・キャッシュ失効・結果無効化と整合させ、適用中断時のロールバックを受入試験に含める。

[配列・出力範囲・総数の現行実装](https://github.com/tak063495-prog/excel-vba-soil-fem/blob/6a9ad0c5bec98a3012d71a18e91f33f6cfab9c9e/src/vba/FEMUiGeometry.bas#L71-L118)

エラーを一行削除するだけの修正は禁止する。登録数で配列や総数を作ると、未使用分の空行が下流へ入り得る。

### 3.3 上限と表示

最小変更では現行のID上限60000と登録上限60000を維持し、使用点にも別途下流の上限を適用する。表示範囲・境界当たり点数等の既存制限は別に維持する。より大きいIDを許す拡張は、全参照の型・変換・入力規則を確認して別途実施する。

表示例：

> 登録100点、使用28点、未使用72点。未使用点は今回の形状生成・解析に使用しません。

形状点IDと生成後のFE節点IDは別の番号体系である。対応表や図の凡例で区別する。未使用の遠方座標をモデル寸法、許容誤差の尺度、自動支持判定、メッシュ品質評価に混ぜない。未使用点のプレビューを表示する場合も、解析用の範囲計算とは分離する。

### 3.4 変更判定と保存

登録台帳の編集と実際の解析モデル変更を区別する。将来的には台帳revisionと、使用座標・境界・材料割当等から作る実効モデルhashを分けられる。ただし、未使用編集だからといって既存の入力一致検査や結果失効を無条件に迂回しない。

Phase Aの最初の実装では、安全側の既存失効動作を維持してもよい。未使用編集だけで既存結果を保持する最適化は、実効モデル同一性・境界条件・保存スキーマを検証してから解禁する。受入条件の「結果不変」は、同じ有効モデルを再生成・再解析して照合する意味であり、旧結果の無条件流用を要求するものではない。

材料領域・境界を追加変更した場合、内部番号や生成FE節点・要素番号が変わり得る。番号指定の荷重・支持・水理・JOINTを再照査し、旧結果・再開状態は無条件に利用しない。[現行の再メッシュ注意](https://github.com/tak063495-prog/excel-vba-soil-fem/blob/6a9ad0c5bec98a3012d71a18e91f33f6cfab9c9e/docs/STAGE_UI_20261024.md#L80)を維持する。

## 4 Phase B 直接FEM入力の任意IDと未接続点

Phase Bは横断改修であり、Phase Aと別PR・別受入判定にする。形状点のID変換が存在することを理由に、直接FEM入力の連番照査だけを削除してはならない。

### 4.1 三層の対応

- `ExternalNodeId`：利用者の節点ID。入力・診断・CSV・図の表示に使用する。
- `InternalNodeIndex`：モデル接続に使う節点のみの連続添字。数値配列に使用する。
- `EquationIndex`：拘束・工程活性・RCM等を反映した変位／水圧自由度番号。

入力IDは整数として正規化して重複を検出する。まず範囲1～60000を契約とし、範囲拡張は別途判断する。内部添字の決定規則は使用IDの昇順を基本案とする。既存1開始連番モデルでは従来順を保つ。RCM等による並べ替えは別の対応として逆変換可能にする。

入力IDを変更した等価モデルでは数値演算順が変わり得るため、比較は外部IDと物理座標の対応を揃えて行う。番号だけで解が物理的に変化することを許すものではない。

### 4.2 使用集合の定義

全工程で定義される要素の接続から、使用節点集合を作る。初期OFFの材料・要素も対象とし、現工程だけを見て削除しない。将来の構造要素・JOINT・MPC等については、機械的または水理的に有効な接続と自由度の契約を定義して使用集合へ含める。

単に荷重表・観測点・対象集合などにIDが出現するだけでは、剛性や拘束のない自由度を追加しない。非ソリッド接続だけで使用可能とする場合は、その要素・拘束が必要な自由度を提供することを検証する。未対応の接続は明示停止する。

未接続点への非零節点荷重、強制変位、支持条件、水頭・流量等の水理条件、JOINT参照は、黙って捨てずエラーにする。荷重ゼロであることだけを理由に誤参照を隠さない。観測・出力専用参照は「解析対象外」と表示してよいが、計算値や反力を作らない。

### 4.3 横断的に変更する範囲

| 対象 | 必要な契約 |
|---|---|
| 節点・要素読取 | 連番・行順依存を対応表へ置換。未定義接続を停止 |
| 荷重・拘束・強制変位・載荷セット | 外部IDを一度だけ解決し、未使用参照を停止 |
| 水理境界・変位水圧連成 | 変位と水圧の対応、透水節点集合、拘束・nullspace処理を保持 |
| JOINT・構造接続・対象集合 | 接続先の番号体系を統一。別体系のIDを混同しない |
| RCM・自由度配列・native引数 | 内部連番だけを渡し、入出力の逆対応を検証 |
| 施工工程・SRM・失敗復元 | 確定状態と試行状態に同じモデル対応表を使い、巻戻し時に整合 |
| ビューア・反力・CSV | 利用者IDで表示。未使用は対象外。生成IDと区別 |
| 保存・再開・モデルhash | 版付き対応表・接続・座標・必要な条件を保存し、一致しない状態を拒否 |

[現行内部マップと接続検査](https://github.com/tak063495-prog/excel-vba-soil-fem/blob/6a9ad0c5bec98a3012d71a18e91f33f6cfab9c9e/src/vba/FEM.bas#L1004-L1116)を起点に、すべての節点ID参照を棚卸しする。既存マップの存在だけで全入力経路への適用完了と判断しない。

保存形式を変える場合はschema versionを更新し、旧形式は連番モデルとして明示変換できる条件だけを受理する。黙った推定で異なる節点に応力・変位・水圧を割り当てない。変換できない旧状態は元版継続または入力からの再解析を案内する。

## 5 回帰試験と受入条件

### Phase A

1. 全登録点を使用する既存モデルについて、内部対応・図形定義・メッシュが従来と一致する。同一実行条件でFs、変位、反力、応力、水圧、残差、診断出力を照合する。
2. 同じモデルへ未使用点を多数追加しても、生成メッシュ・モデル尺度・自動支持・解析値が変わらない。極端に遠方の未使用点を含める。
3. 外部IDを101、205、310等に変更し、座標行を並べ替えても、同じ境界順・座標から同じメッシュを作る。1以外開始を含める。
4. 未使用点を材料領域へ追加すると正しく使用へ昇格し、必要な結果失効と番号条件の再照査が働く。
5. 未定義ID、重複ID、空欄・非数値座標、境界内重複、不正共有・自己交差を拒否し、拒否・中断で以前の有効入力を壊さない。
6. 穴、複数材料、共有材料境界、初期OFFからBIRTHする領域を含む。境界の意味と既存の適合接続検査を維持する。
7. デローニと地形格子の両経路で確認する。元々適用できない形状や番号条件を、本変更によって誤って受理しない。
8. 配列数、対応表数、出力座標数が常に一致し、未使用分の空行が下流へ流れない。
9. 正常終了、入力エラー、適用途中エラー、中断、保存・再読込を確認する。警告一覧のID・元行も一致させる。

### Phase B

1. 既存1開始連番モデルで内部順、行列、Fs区間、変位・応力・反力・水圧・診断を従来と照合する。同じ演算経路では完全一致を基準にし、差があれば理由を説明して受入判定を保留する。
2. 外部IDの飛び番・1以外開始、行の並べ替えを独立に試す。純VBAとnativeの両方で、外部IDへ戻した結果を照合する。
3. 未接続点追加で自由度数・行列・解が変わらず、対象外表示になることを確認する。
4. 未接続点への荷重・拘束・水理・接合参照を検出する。全固定など特殊条件で偶然特異行列が出ないことを受理理由にしない。
5. 後工程BIRTH、掘削、材料変更、SRM分岐、失敗・中断・再試行で対応表と履歴を保持する。
6. RCMあり／なし、時間連成、水理境界、荷重セット、JOINT、CSV・図・反力のID対応を確認する。
7. 保存再開と連続実行を比較し、ID対応・接続変更後の旧状態を拒否する。旧連番保存形式の受理・拒否条件を試験する。
8. 未定義・重複・小数・範囲外IDを停止し、最大IDに比例した巨大配列を作らないことを確認する。

数値比較の許容値は、実装前に対象ケース・比較量・絶対／相対スケールを固定する。結果に合わせて収束許容値や材料パラメータを変更しない。数値非収束を物理的破壊と断定しない。

## 6 実装順序と完了判定

1. 入口が形状入力か直接FEM入力かを、実際の入力表と照査メッセージで特定する。
2. Phase Aの登録／使用分離、使用数による出力、警告一覧、失敗時非破壊を実装し、上記試験を通す。
3. 対応ブックへ反映する際は、ソースと埋込VBAの一致、コンパイル、実Excel操作、保存再開を検証する。ソース修正だけで配布ブック対応済みとしない。
4. Phase Bが必要なら、番号参照一覧と保存互換契約を先に作り、純VBA経路、native経路、施工・水理・出力の順に検証する。
5. 既存の全点使用・連番入力を維持でき、未使用点の保管が解析の自由度や物理モデルを変えず、誤参照を検出できることを受入条件とする。

本書の公開は設計案の共有であり、実装・マージ・配布更新の完了を意味しない。
