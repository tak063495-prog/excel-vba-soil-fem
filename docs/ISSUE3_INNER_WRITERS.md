# Issue #3：内側CSVライタの中断伝播

[追加指摘](https://github.com/tak063495-prog/excel-vba-soil-fem/issues/3#issuecomment-6367904092)を修正。計算識別`20261024_FIXED_STRESS_07`と保存列は保持し、倍精度・材料則・力学/連成収束条件・SRM探索条件・DLLは変更しない。

## 修正

`PlasticLogWrite`、`FSWriteCheckpoint`、`FSLedgerWrite`、同じ経路の`GWWriteCheckpoint`で、後始末前にErr.numberを保持する。所有ファイルを閉じ、Err18なら中断フラグを設定して18を再送する。外側の工程/時刻保存へ18が届くため、一時フォルダーの削除と既存の受理状態復元へ進む。

通常エラー5の扱いは区別する。工程保存では塑性診断のWARNまたは工程保存の中止として解析を継続する従来の扱いを保持。時刻別状態を保存できない場合は一般の保存エラーで停止し、ユーザー中断へ置き換えない。

## 改修前の再現

元の配布ブックSHA256 `98952de07b4cf389ee4503704a2824a1cfc3a7210d3a04a4fe570df168b2d251`に対し、専用コピーの行ループへ1回だけErr18を注入した。

|注入点|観測|
|---|---|
|PlasticLogWrite、工程保存|中断フラグが立たずPASS。後続WAIT付き入力では86,400→95,040秒、受理11→12刻み、確定増分17→18まで続行|
|FSWriteCheckpoint、時刻保存|Err18が一般保存エラー−2147213374へ変換されRUNTIME_ERROR。ユーザー中断として扱われない|

`before_*`は不具合を再現した記録で合格件数に含めない。待機・注入・測定の補助コードは検証コピーだけに追加し、配布ブックに含めていない。
