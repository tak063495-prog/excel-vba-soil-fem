# 中断処理とQ8要素の全域Jacobian検査

1024配布ブックのIssue [#3](https://github.com/tak063495-prog/excel-vba-soil-fem/issues/3)の残件と、新規Issue [#59](https://github.com/tak063495-prog/excel-vba-soil-fem/issues/59)を修正した。計算識別は `20261024_FIXED_STRESS_07`、保存形式と7画面の入力操作は共通。倍精度、材料則、力学・連成収束条件、SRM探索条件を維持し、DLL1個は変更していない。

## 中断が通常の再試行へ戻る問題

従来の配布ブック（PR #58の `e290fb9`）では、fixed-stress反復のDoEvents位置へErr18を1回注入すると、中断時刻8,640秒・受理2刻みから86,400秒・受理20刻みまで継続し、PASSになった。増分・塑性状態の保存とCSV出力にも、Err18を通常エラーとして消費する経路があった。

Err18は中断フラグを設定して外側の中断処理へ伝える。試行中の力学・水理・境界変位と水量台帳を直前の受理状態へ戻し、時刻別出力の一時ファイルを後始末する。通常の数値不収束の刻み半減と、任意出力の通常エラーの扱いは維持する。

|検証|結果|
|---|---|
|VBA単独／DLL併用、それぞれ初回刻み・受理後のFS・キャンセルフラグで戻る経路・増分取得・増分保存・塑性保存・時刻CSV・工程CSVの8条件|16条件でErr18と中断メッセージが外側へ到達。受理時刻・刻み数・確定増分数の追加なし|
|受理状態の比較|各中断で全86変位・全32積分点水圧・全86境界変位・水量台帳48項目の差がすべて0|

|実際のCtrl+Break|受理2刻み後のFSTryStepのDoEvents位置に待機処理を置いた専用コピーへ実キーを送信。Err18、中断メッセージ、受理状態保持に合格|
|Excel設定の復旧|実キー試験でイベント有効・画面更新有効・自動計算・元のEnableCancelKeyへ復旧|

CAPTURE中断では変位・水圧が戻っても、水量台帳48項目の最大差8.17794e−5が残ることも実Excelで再現した。台帳の受理時スナップショットを保持し、通常reject・中断の両方で戻す修正を加えた。

注入用の待機処理・補助関数は検証コピーだけに追加し、配布ブックへ含めていない。

## Q8内部の折返しを見逃す問題

Q8の四隅と4点GaussのdetJが正でも、要素内部が反転することがある。Issue指定座標では旧8点の最小値は+0.12、161×161点の独立評価では−0.443984375だった。別の固定座標例では、境界の極値評価と旧8点が正でも内部が負になった。

Q8のdetJは自然座標ξ・ηのそれぞれについて高々3次である。4×4点からその多項式のテンソルBernstein係数を構成し、係数の凸包で参照正方形全体の下限を判定する。下限だけで正値性を確認できない領域はde Casteljau法で二分する。点の符号だけでは受理しない。

座標は要素内で平行移動・正規化する。根の係数規模から求めたDoubleの丸め余裕を全子領域へ引き継ぎ、深さに応じた余裕も加える。最大深さ24・最大4,096領域で正値性を確認できなければ、要素番号と理由を示して拒否する。著しく歪んだ正要素も安全側に拒否される場合があるため、辺中点・輪郭・要素の切り方を見直す。

入力時の品質検査と、要素行列を作る前の座標検査の両方へ接続した。T6とJOINTの専用検査は維持する。

|実Excelの検証|結果|
|---|---|
|Issue指定の反転、境界全体が正で内部だけ反転する例|要素番号付きでINPUT_ERROR。確定増分0|
|退化・極短辺・既存の絶対Jacobianしきい値未満|入力エラーとして停止。相対的な正値性を満たす微小正方形と、実行時の絶対しきい値は区別|
|正方形、回転・拡大、正当な曲辺、1e9の平行移動＋1,000幅|4入力とも解析完了。反力と自重の釣合いに合格|
|認証関数と実行時検査|9形状を双方から検査。相対認証だけなら1e−6幅の正方形も受理|
|細分が必要な正当な曲辺Q8|根のBernstein下限−0.0606564、密評価最小+0.341962。細分後に認証・実行時検査とも受理|

独立Python検算はQ8形状関数の微分からdetJを求め、旧8点・161×161点・境界の三次多項式の極値を評価する。密評価の正値だけを、全域認証の代わりにはしていない。
