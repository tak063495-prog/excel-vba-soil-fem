## 診断値と保存データ

正のダイレイタンシー角ψの頂点では、工学せん断成分を除く塑性ひずみの跡から

`ΣΔλ = -(Δεpx + Δεpy + Δεpz) / (2 sinψ)`

を得る。同じ正規化の面・稜線リターンと整合する。ψ=0の頂点では主塑性ひずみの最大値と最小値から `max(εp_max, -εp_min, 0)` を用いる。履歴の塑性ひずみそのものや、累積塑性せん断ひずみの定義は変更しない。旧版の頂点における塑性乗数と新版の値は、定義が異なるため直接比較しない。

旧計算識別の途中保存データはその版のブックで継続するか、新版で入力から再解析する。異なる計算識別のチェックポイントを混在させない。

## 再現方法

Excelをすべて終了した状態で、配布ブックの専用コピーを用いる。元ブック・ユーザーのExcelは変更しない。

```powershell
pwsh -NoProfile -File tests/run_issue49_57_regression.ps1 -Book workbook/ui_20261024/2DSoilFEM_ui_20261024.xlsm -Out <新規フォルダー>
python -X utf8 tests/check_issue49_57.py --root <新規フォルダー> --book workbook/ui_20261024/2DSoilFEM_ui_20261024.xlsm --out <新規フォルダー>/check.json
pwsh -NoProfile -File tests/run_issue54_55_material.ps1 -Book workbook/ui_20261024/2DSoilFEM_ui_20261024.xlsm -Out <材料点の新規フォルダー>
python -X utf8 tests/check_issue54_55_material.py --actual <材料点の新規フォルダー>/material_points.json --out <検算結果.json>
```

[再現入力](../tests/fixtures/issue49_57)と[材料点入力](../tests/fixtures/material_issue54_55.json)に条件を保存する。材料点は実Excel内の製品ルーチンをテスト専用入口から呼び、Pythonでは元の6流れ方向による非負線形計画、弾性再構成、降伏関数、乗数の和と照合する。微小ψでは線形計画自体のランク判定に依存せず、構成が既知の流れ方向を用いる。

完了した全数値照合・実行時間・配布ブックのSHA256は検証集計に記録する。

材料点の診断コード4105は既存の `P2_FAILURE_VERTEX`（頂点リターン）識別で、上記の成功例はAPIの戻り値・convergedともTrueである。複数分割とψ=0の非滑らかな境界では従来どおり差分接線を使い、接線の解析式採用フラグを無理にTrueにしない。

時刻別反力の検算は、保存した全応力から有効応力を戻し、`−∫Bᵀσ' dV − Qp`を独立に積分して節点内力を求め、自重・外力を差し引いた。1次元変位場を確認した柱を使い、この場合にhourglass力が0となる前提も検査した。合計反力だけでなく全節点のI/J列を比較する。
