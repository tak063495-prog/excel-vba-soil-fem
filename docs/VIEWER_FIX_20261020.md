# 計算後の「変形・応力図を表示」の修正

対象は `2DSoilFEM_ui_20261020.xlsm`、画面版 `20261020_UI_02` です。ファイル名は変更していません。計算版 `20261020_INCO_ELEMENT_01`、材料則・Double・収束条件・SRM条件、DLL 2個は維持しています。

## 再現した問題と修正

1. **表示設定を変えると再解析を要求される。** 用途別設定の変更通知が、`VIEW_` 等の非解析キーでも常に保存結果をdirtyにしていました。変位倍率や表示項目を変えるだけで、成功結果を表示できなくなります。解析を無効にするキーの場合だけdirtyにするよう修正しました。材料・節点・要素・載荷・ステージなどの変更では、古い結果を引き続き拒否します。
2. **手動計算モードで表示値が古い。** ビューアが旧「設定」シートの値を直接読んでいたため、用途別C列からの参照式が未評価のままになる場合がありました。「出力・表示」の式、続いて旧設定のリンクを評価してから読み込みます。解析結果を再計算する操作ではありません。
3. **保存後に開き直すと結果がdirtyになる。** `Workbook_Open` の画面・設定レジストリ整備がSheetChangeを発火し、ユーザーの物理入力変更と誤認されました。起動時の画面整備中だけイベントを抑止し、成功・失敗にかかわらず元のイベント状態へ戻します。保存済みのdirty値そのものは変更しません。材料を変更して保存したブックは、再読込後もdirtyのままです。

表示エラーには、エラー番号と「表示設定の読込」「保存結果と入力の照合」「一時SVGの保存」「Excelへの図の挿入」「図シートの表示」の段階を加えました。別の失敗が残る場合も、発生位置を切り分けられます。

## 検証

旧配布ブックのコピーで初期/全体/結果の表示が成功することを確認した後、表示倍率だけを変更すると再解析要求で拒否される問題を再現しました。手動計算で表示倍率の参照式が古いままであること、保存・再読込でcleanな結果がdirtyになることも修正途中のテストで再現しています。

修正版の表示試験は次を含みます。

- 68種類すべての表示項目で、ExcelへのSVG図形挿入が成功。
- 倍率・色付け項目・色スケール・詳細表示・従来表示元、ログ/再開設定を変えても、成功結果を再表示可能。
- 手動計算でも表示値とC列の設定式を評価。
- 材料・メッシュ・解析条件を変更すると古い結果の表示を拒否。
- DLLを使わない小モデルの実計算後に倍率を変えて表示成功。
- 成功結果を保存→再読込→表示項目変更で再表示成功。
- 材料変更を保存→再読込ではdirty状態を維持し、古い結果の表示を拒否。
- 配布元ブックを上書きせず、コピーだけを使用。

配布XLSMでも表示108項目、既存の入力813項目、保存・互換性407項目の計1,328項目がPASSです。VBAコンパイル、ThisWorkbookを含む14モジュールの保存前後・再読込ソース照合も成功しています。

## 利用時の注意

計算後の表示専用変更なら再解析は不要です。材料・境界条件・メッシュ・載荷・ステージ・解析条件を変えた場合は再解析してください。以前のUI_01で既に誤ってdirtyとして保存された結果を、自動的にcleanへ書き換えることはしません。新しい版で再計算してから表示を確認してください。

表示試験のExcel環境ではSVG挿入が成功しています。SVG非対応のExcelや書き込み不能なブックフォルダー等、環境固有の失敗をすべて解消したという意味ではありません。エラーが残る場合は、追加された番号と表示段階を確認します。

## 再現手順

Excelをすべて閉じ、リポジトリのルートで実行します。テストは自分で作成したExcelと作業コピーだけを扱います。

```powershell
pwsh -NoProfile -File tests/test_viewer_display_settings.ps1 -Book workbook/ui_20261020/2DSoilFEM_ui_20261020.xlsm -Out tests/results/viewer_checks.json
```

修正前の配布版を使う場合は `-ExpectDirtyBug` で誤ったdirty化を再現できます。開発時の `-UseSource` はコピーのFEMUi・FEMViewer・ThisWorkbookだけを差し替えて検証します。

PDF説明書はUI_01を基準に作成した版です。入力配置・操作方法は共通で、本修正の差分はこのページを参照してください。
