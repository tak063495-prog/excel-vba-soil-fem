# PR #34 シート設計試作

[自作プリセット試作](PR34_CUSTOM_PRESETS.html)をダウンロードしてブラウザーで開くと、工程/操作の編集、組込みプリセット、自作プリセットの保存・読込を確認できます。Excelブックや数値ソルバーを変更・起動するものではありません。

## 操作

1. 「開始プリセット」→「構成を確認」→「この構成で新規案を作成」で、工程案を作ります。適用後も工程/項目の追加・複製・削除・順序変更ができます。
2. 工程名、対象、期間、初期力等を編集し、対応する「反映」を押します。自作保存には反映済みの入力を使います。
3. 「自作プリセットとして保存」で名称・説明・保存方法・保存範囲を選び、「自作一覧へ保存」を押します。
4. 「自作一覧・読込」から「読込を確認」を押します。工程構成のみなら、保存slotの型に適合する現モデルの対象を明示的に選びます。対象を含む保存なら、保存定義を複製する方式も選べます。
5. 「新しい案へ読込」で新しい対象/工程/項目IDへ展開します。元の編集案と保存版は保持し、読込後に「04 確認・計算」で入力・順序を確認します。

同じ自作IDの改訂は新revisionに保存し、過去版を上書きしません。組込みプリセットは読取専用です。

## 保存範囲と持出し

|保存範囲|この試作で保持する内容|
|---|---|
|工程構成のみ|工程、操作、解析区間、照査、内部参照、対象slotの型・単位・断面。作用値/期間/区間内時刻は再入力|
|対象集合と項目入力値を含む|上記に加え、現在の対象集合すべての型・初期活性、項目パラメータの入力値|

形状座標、メッシュ、節点/要素割当、地盤物性の詳細や外部の確定stateはこの試作には登録されていません。計算結果・反力・応力履歴・checkpointも保存しません。「対象を含む」はモデル全体の再解析可能なバックアップという意味ではありません。

一覧への保存は試作内のデータ保持です。ホストが対応する場合は小さい状態を再表示用にキャッシュしますが、ブラウザー/会話再起動後の永続性は保証しません。持ち出す場合は「JSONを書き出す」の内容をコピーしてUTF-8の `.json` に保存し、「JSONから読込」へ貼り付けて再登録します。自動のファイル書込・ネットワーク送信は行いません。

[読込用JSON例](pr34-custom-preset-example.json)は「工程構成のみ」です。現モデルに対する地盤slotの明示対応付けを試せます。

## 検査と制限

JSONは形式/辞書版、許可フィールド、ID重複、内部参照、対象型・単位・断面を検査します。上限は128KiB・階層12・工程100・項目500・対象200です。壊れた形式、未知操作、式/コードを含む数値、外部の確定stateを拒否します。既知だが未解禁の解法/組合せは計画として表示し、実解析は起動しません。

対応付け方式では、現モデルの対象集合全体を新案へ複製して解析文脈を保持します。その一覧は読込プレビューで展開表示できます。対応先は型が一致するものを一対一で選び、同じ名前/IDという理由だけで自動結合しません。

## 再現確認

Node.jsの標準モジュールだけを使います。

```powershell
node docs/prototypes/pr34-custom-presets.test.cjs
```

配布HTMLのソースを読み、保存範囲、版管理、JSON再登録、非破壊読込、全namespaceの新ID、内部参照、エラー時の非変更、組込み不変、状態キャッシュ、公開JSON例を検査します。検査用の関数公開はテスト環境内だけで行い、HTML本体には追加しません。
