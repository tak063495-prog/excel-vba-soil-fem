# 工程ごとの時間圧密・水位変動

1024版の7画面から、小ひずみ・飽和Biot連成を工程単位で実行する。施工荷重、水位、排水条件を指定し、fixed-stress反復で水理と力学を収束させる。時間は内部で秒、長さはm、力はkN、応力・水圧はkPaを用いる。計算はDoubleで、既存の材料則・収束条件・SRM探索条件を引き継ぐ。

## 入力する順序

1. **材料・接合 → 材料特性**で地盤の排水骨格のE、ν、強度・流れ則、全重量を設定する。水の重量を別に加算したり、浮力分を土の重量から二重に引いたりしない。
2. **材料・接合 → 材料の水理特性**で対象地盤をEFFECTIVEにする。**圧密材料特性**に材料番号、Biot係数α、貯留1/M、kx、kyを登録する。貯留は1/kPa、透水係数はm/s。飽和地盤を盛土・掘削する場合は間隙率nも必要になる。構造体はTOTALのまま、地盤とは別に設定する。
3. **境界・水条件**に水位線と水理境界を登録し、水圧確認図で初期水圧・外水圧を確認する。最初のGRAVITYは片方向で初期平衡を求める。初期の静水圧または定常浸透圧を時間連成の初期値に引き継ぐ。
4. **施工工程 → 工程の編集**で盛土・載荷・時間経過・水位変更・SRM等を並べる。工程IDに対応する**時間・連成設定**と**時間の詳細設定**を入力する。
5. 解析後、**結果 → 時間履歴／水量収支**で受理した時刻と収束を確認する。**時刻別の図**で工程・累積時刻・施工本線／SRM照査枝を確認して保存状態IDを選び、「この時刻を表示」を押す。表示項目・倍率・増分図は従来の表示設定を使う。別の保存状態を選び直す場合は「時刻別の図」に切り替えてから指定する。

## 工程の設定

|項目|動作|
|---|---|
|ONE_WAY|従来の指定水圧・定常浸透から力学への片方向解析|
|FIXED_STRESS|時間連成を開始する|
|INHERIT／空欄|直前の方式を継承する。時間連成開始後は水圧・履歴を保持する|
|工程時間・初期刻み|「時間の詳細設定」の秒／分／時間／日の単位で入力。未指定単位は秒|
|反復上限・許容値|未指定時は100回、1e-8。流体の元の方程式・水量・反復変化と、既存の力学収束条件を確認する|
|最小・最大刻み|未指定時は初期刻み/1024、初期刻み。失敗時は受理前の状態へ戻して刻みを半減する|
|保存間隔|0または空欄は全受理時刻の全場を保存。正数なら指定間隔と工程末を保存し、他の受理時刻は要約を残す|

時間経過（WAIT）は正の工程時間が必要になる。時間0の載荷・盛土・掘削は、時間を進めない初期応答として扱う。載荷方法をLINEARにすると、正の工程時間内で荷重と強制変位を線形に変化させる。BIRTHでは要素自体を最初に有効化し、自重荷重を時間内で増加させる。要素の剛性を徐々に増加させる操作ではない。

時間連成開始後のONE_WAYへの切替は、残存過剰水圧を消してしまうため停止する。全体共通の旧CONSOL_*設定やMIXED_UP設定は使わず、この工程別入力を使う。

### 盛土と途中照査の例

|工程ID|操作|方式|工程時間|水位変化|確認する結果|
|---|---|---|---|---|---|
|1|GRAVITY|ONE_WAY|0|初期水位|初期平衡、水圧、反力|
|2|BIRTH：盛土材料|FIXED_STRESS|0|HOLD|直後の沈下・過剰水圧|
|3|SRM|継承|0|親水圧保持|盛土直後のFs|
|4|WAIT|INHERIT|30日|HOLD|圧密沈下、水圧消散、水量|
|5|SRM|継承|0|親水圧保持|30日後のFs|
|6|WATER：次の水位線|INHERIT|5日|LINEAR|水圧・流束・外水圧の変化|
|7|BIRTH／LOAD|INHERIT|施工時間|HOLD|次の施工と圧密|

水位を保持するのは境界条件である。内部の過剰間隙水圧は固定せず、荷重と時間に応じて変化・消散する。工程IDは順序とは独立で、追加・複製・削除・移動・元に戻す操作では関連する時間詳細も引き継ぐ。

### 水位の変化と排水

水位の空間折れ線は従来どおり登録する。時間方向はWATER工程でHOLD／START／LINEARを指定する。中間の折点が必要なら「水位の時系列」に、同じ時系列ID、工程内時刻、水位線IDを時刻昇順で登録する。開始時刻0から工程終了時刻までの2点以上が必要で、水位線間を時間補間する。時刻の単位は当該工程の単位を使う。

WATER工程に工程別水理・時間設定（元表L:T）があり、時間詳細行（AC:AL）を登録しない場合は、開始時変更（START）として対象水位を使う。時間詳細行を登録して水位変化を空欄にした場合は保持（HOLD）である。保存再開でも同じ既定値を適用し、完了したWATERの境界水位・外水圧荷重を次のWAITへ継承する。指定された時系列がある場合は、その工程内時刻の補間を優先する。

材料・境界の水位線欄が`*`なら工程の水位変更を継承する。個別の水位線IDを指定した境界は固定される。工程の採用水位線は、水条件N列→ステージC列→既定B5。N/Cが異なる場合は停止する。WATER以外の工程では境界水位を変更しない。

排水条件セットが空欄なら直前の条件を継承する。非空欄のセットは通常の排水・流束条件を**置換**する。セットにない面は流束0となる。JOINT固有の指定水頭条件は保持し、外水圧の設定は排水条件とは別に扱う。

|種別|指定値|
|---|---|
|HEAD|全水頭[m]。水位線IDを入力した場合はその線の水頭を使う|
|PRESSURE|水圧[kPa]|
|FLUX|境界面から内向きを正とした流束[m/s]|
|NOFLOW|外周面・水理分離JOINT面の流束0。共有内部透水面への指定は拒否する。水圧0ではない|

要素番号・辺番号は生成済みメッシュに対応させる。再メッシュ後は番号との対応を再確認する。排水セットの同一辺重複や、共有圧力節点に異なる指定値を与える入力は停止する。

### 工程別の載荷セット

「載荷条件」の載荷セットID（元表K列）と、時間詳細の載荷セットID（元表AK列）を一致させる。時間連成のLOAD/APPLY/UNLOADに使用する。

セット内で指定した自由度の荷重・強制変位を目標値へ上書きし、指定していない自由度は直前の受理状態を継承する。同じ自由度のFORCE行は加算する。FORCE=0も明示的な解除として有効。DISPは絶対変位[m]、FORCEは節点力[kN]、FIXは変位0である。座標BOXやTOP等、従来の対象節点指定を使用できる。

空欄の載荷セットIDは従来の全体載荷表として処理する。名前付き行を従来の空欄セットへ混入させない。

## SRMと後続施工

SRMは施工本線の状態を親として複製する。Fs試行中はその時点の水圧と時刻を保持し、各Fs試行は同じ親状態から始める。追加の圧密や非排水過剰水圧はSRM中に計算しない。

照査後は強度低減前の材料・応力・変位・塑性履歴・荷重・拘束・有効要素へ戻して、次の施工へ進む。結果のCは施工本線、Sは水圧保持のSRM照査枝。Fsの図を、そのまま次の施工の初期状態と解釈しない。

## 結果・保存・再開

|出力|内容|
|---|---|
|時間履歴|工程ID、累積秒、実刻み、連成反復、流体残差、水量誤差、力学残差、最大変位、施工本線／照査枝、保存先、親状態、Fs|
|水圧結果|全水圧、全応力・有効応力、全水頭、Darcy流束、過剰水圧の基準と差分|
|水量収支|各受理刻みの貯留変化、骨格体積変化、指定圧・指定流束からの流入、閉合誤差、施工持込・掘削持出水量|
|外部の時刻別フォルダー|全節点・積分点、材料履歴、水圧・基準場・時間工程、領域水量等のチェックポイント|

水圧確認図の入力水位線と、保存時刻の計算全水頭・水圧を区別する。時間変化する境界は開始・終了水位線から補間されるため、登録した終了水位線をそのまま途中時刻の計算結果と読まない。

過剰水圧の基準は初期活性化時の積分点水圧で、BIRTH要素はその有効化時を基準にする。水位が変わっても基準を自動で置き換えない。非透水構造体の未計算水頭を地盤の計算水頭として使用しない。

水量は厚さを含むm³。貯留＋骨格体積変化＝境界流入量の関係を確認し、領域増減による持込・持出水量を境界流量へ混ぜない。間隙率を指定していない既存地盤では相対変化のみとなり、湿潤掘削は絶対水量を定義する間隙率が必要になる。

ブックと時刻別出力フォルダーは一緒に移動・保管する。保存間隔で全場を省略した要約行は、図や再開に使えない。再開先に保存された受理フォルダーを指定すると、途中工程の残り時間から継続する。SRM枝は図の確認用で、施工本線の再開先には使えない。入力の変更や署名不一致を検出した場合は、古い状態からの再開を拒否する。

## 対応範囲

Q8変位／Q4圧力、および直線辺T6変位／P1圧力の飽和連成。MCのDAVIS／INCONSISTENT、線形構造体、既存JOINTの固定された水理接続を用いる。JOINTの開口が1e-8 mを超えた時間連成状態は、空隙内の流体貯留を別途モデル化する必要があるため受理しない。

未知の自由水面、不飽和化、浸出面自動切替、過渡圧密中のRESET_U／RESET_STRESS／MATSET、施工途中の再メッシュ、クリープ、有限変形、新しい梁・軸対称連成は対象外。反復途中の試行値と受理状態を区別し、受理候補に負の水圧が生じる場合は理由を示して刻みを再試行・停止する。閉鎖・貯留0・体積拘束で水圧の基準が定まらない入力も停止する。

固定応力分離法の基礎：[Kim, Tchelepi and Juanes (2011)](https://doi.org/10.1016/j.cma.2010.12.022)。二次元検証の解析解：[GEOS Mandel benchmark](https://geosx-geosx.readthedocs-hosted.com/en/latest/docs/sphinx/advancedExamples/validationStudies/poromechanics/mandel/Example.html)。
