# INCONSISTENTの接線・全体反復・非収束判定の修正

対象: `20261009_INCO_14` / 操作・結果処理 `20261009_PRACTICAL_04`。

後続版の悪条件行列の再求解、材料内力による釣合い確認、SRMの回復反復は [INCONSISTENT SRMの追加改修](INCONSISTENT_SRM_IMPROVEMENT.md) に記録する。本書の試験値は当時の版の履歴である。

INCO_14の数学的な計算経路を使った複数斜面の限界Fs探索、INCO_15の停止時Fs保存値の修正、INCO_16のFs<1探索への引き継ぎ修正は、[限界安全率と実用性の追加検証](PRACTICAL_SRM_VALIDATION.md)に追記した。本書の旧測定値・ハッシュは当時の版の記録として保持する。

旧R1では、Griffiths斜面のINCONSISTENT・ψ=0で、Fs=1の自重が約79.6%までしか載らず、全探索でも論文より低い数値が表示された。部分的な載荷状態の非収束を設計安全率と扱えないため、材料更新、非対称行列、Newton反復と失敗の扱いを修正した。[旧R1の記録](LITERATURE_VALIDATION.md) は過去の結果として残す。

## 修正内容

### 材料点

`INCONSISTENT` は互換性のため残す選択名で、非関連流れ則を選ぶ。今回の経路では材料接線を対称化しない。主応力の大小順位と面内／面外の物理成分の対応をtrial状態で固定し、面・上下の稜線・apex復帰を同じ基底で判定する。塑性乗数の符号、主応力の順序、降伏面、ψ=0の塑性体積ひずみを検査する。

単一ステップの通常の面・稜線復帰では、主応力の順位変換と面内主軸回転の微分を含む解析式の非対称接線を使う。ψ>0でapexの塑性流れ錐の厳密な内部にある単一ステップは、一定のapex応力を返すため解析的なゼロ接線を使う。境界・ψ=0・主軸が退化する場合・複数サブステップでは、接線を応力更新全体の有限差分から求める。主軸回転と採用した材料サブステップを含めて再計算し、3列がそろってから確定する。微分幅はひずみ増分と応力／Eに加え、材料判定の許容誤差を各サブステップで分解できる下限を設ける。静水圧を除いた応力・粘着力・増分から局所的な幅の上限を設け、両立しない接線は成功にしない。幅hとh/2の微分値が相対1e-4以内で一致し、中心／片側の方向も一致することを確認する。縮小時も分解能の下限を守る。材料状態を戻せない試行は成功にしない。旧自己テストの2つの引張側入力は、ψ=0では帰着不能な入力として棄却を確認し、成功用の入力を別に用意した。

### 行列と全体反復

INCONSISTENTでは現在の全要素接線を毎回組み立て、上下両側の非対称成分をCSRに保持する。初期弾性行列のキャッシュを現在の塑性行列として再利用しない。主解法は行部分pivot付き非対称帯LU、失敗時は右前処理GMRESで、現在の行列による真の線形残差を確認する。非対称行列を対称帯LUへ戻す経路は使わない。負のpivotだけで破壊と判定しない。

Newton補正がラインサーチで改善しない場合は、最初の補正倍率1・1/2・1/4について最大6段のNewton補正を先行試行する。途中の残差増加は元残差の100倍まで許容するが、元の残差を減らした合成補正だけを採用する（`NEWTON_WATCHDOG_ACCEPT`）。棄却時は変位・材料状態・接線行列を元に戻し、特異行列・容量不足・入力・実行時・中断の停止理由を保持する。それでも改善しない場合は、列スケールを施した正則化付き残差補正を試す。これは応力・強度・流れ則を変える処理ではない。材料検査と同じ残差検査を通った補正だけを使う。元の行列と主線形残差を保ち、正則化方程式の残差は別イベントに記録する。全体反復はINCONSISTENTで最大100回。先行試行と正則化回復の求解も同じ増分の予算に含め、99/100回の境界で追加求解と状態復元を確認した。残差が許容値を超え、微小な補正で改善率が1%未満の状態が4回続く場合は、停滞として増分を縮小する。最終の残差・補正・拘束変位の許容値は緩めていない。

施工で拘束が変わるときは、CSRの拘束抽出キャッシュも更新する。旧抽出ではTOPの指定変位に対角1を与えられず、力残差だけが小さくなって反復上限へ達していた。RCMの自由度並べ替え時は、旧番号に依存するCSRパターン・散布位置・数値値・拘束・前処理を破棄し、要素ローカルの弾性キャッシュを保持する。OFF→ONと同じ写像の再適用で、原節点順の変位と最大応力が一致することを確認した。

外力をゼロへ除荷するときは、直前の確定外力のノルムを力の基準に残す。ゼロ目標の1e-12を基準にして丸め誤差を過大評価する反復を修正した。確認した除荷小モデルでは分解447回から14回へ減り、変位のゼロ復帰を確認した。変位載荷の反力基準も残す。

DAVISの保存値と材料変換は変更しない。関連接線の対称性検査は、ゼロに近い個々の成分ではなく要素行列全体の大きさで正規化し、数値微分の丸め誤差による誤拒否を避ける。

### 非収束とFOS

|判定|扱い|
|---|---|
|材料更新・線形ソルバ・容量・入力・実行時の失敗|`NUMERICAL_FAILURE`。SRM上限の根拠にせず探索停止|
|微小補正の停滞|`GLOBAL_STAGNATION`。数値失敗として扱う|
|塑性を伴う反復回数／ラインサーチの限界|収束境界の候補。成立した区間も`NUMERICAL_BRACKET`で、物理破壊や設計安全率の確定ではない|
|数値失敗による探索停止・固定Fs検証の失敗|`UNDETERMINED`、FSS=0、上限・中点・区間幅を無効化。固定Fsの成功は安全率探索の結果ではない|

探索中止時に残す「最後に収束したFs」は診断情報であり、失敗後の結果表をそのFsの確定状態と解釈しない。失敗直前の残差・λ・補正比・塑性点数・変位を、状態を戻す前に記録する。成功した試行でも過去の棄却記録は保持するため、失敗原因の欄だけで現在の成否を判断せず、ResultStatus・試行分類と併せて確認する。

## 確認結果

材料・ソルバ・判定の198条件と既存の回帰試験を、配布版の同じハッシュで照合した。[検証集計](inconsistent-evidence/verification_summary.json) に実測と各証跡を保存する。INCONSISTENTの施工・載荷10条件と30表示、RCMの原順序変位・応力一致も確認した。文献斜面については下記の検証範囲を区別する。

- 独立した6面active-set計算との材料点75ケース。面・上下稜線・apex、面外主応力の各順位、主軸回転、ψ=0/関連流れ、有限差分接線、strict apexの内部と境界を比較。
- 独立した材料更新を合成した50条件。4・8分割の応力、塑性ひずみ、全写像の接線、回転したψ=0 apexの片側微分、過大な拘束圧で接線精度を確保できない場合の棄却を確認。弾性状態は分割を省略する。
- 中心／片側の差分が幅間で混在する2制御条件。数値が同じでも方向が異なる接線を棄却し、未採用列を部分確定しないことを確認。
- 非対称線形ソルバ26ケース。pivot、帯域のfill、拘束変位、ゼロ／微小荷重、特異系の棄却、容量拒否、失敗時の変位不変を比較。拘束抽出を一度生成した後の拘束追加・解除・変更も確認。
- 独立した密行列計算との正則化補正28ケース。特異行列、荷重・剛性のスケール、拘束、無効damping・容量拒否、主行列／診断の不変を確認。
- 線形非収束・特異・容量の3原因を探索／固定Fsの計6条件へ注入し、偽の上限・FSSが残らないことを確認。
- 探索の最終状態復元／最終再解析に失敗する2条件。過去のFSS・上限・中点・幅を故意に残した状態から、無効化と表示Fs=0を確認。
- 先行Newton試行と回復予算の9条件。合成補正の採用、全棄却時の変位・接線・線形診断復元、特異・中断・容量の理由保持、材料checkpoint復元、NewtonとLMの99/100回境界を確認。制御試験では力を合成関数で与え、配布版の復元・反復処理を呼ぶ。
- 原ブックの材料・節点・要素・接合・載荷・ステージと、保存設定74項目を保持。VBAプロジェクト全体をExcelでコンパイル。

## 使用時に確認する場所

「解析設定」C10の`FLOW_POLICY`でINCONSISTENTを選択する。保存済み結果は再解析してから使用する。INCONSISTENTでは保存フラグが1でもV2a/V2b/V5を休止する。これらは従来の対称帯LU再利用を前提とするためで、毎回の非対称接線を優先する。V1/V4と適応選別の設定は残すが、実行適格性によって候補が使われない場合がある。

「診断」の142〜150行に`FOS_INTERPRETATION`、試行分類、失敗原因、失敗時λ・全体残差・線形残差・補正比・塑性点数・最大変位を出す。`perf_summary.csv`にも同じ情報を追加し、`solver_events.csv`に`REJECTED_ATTEMPT`、`REGULARIZED_SOLVE`、`REGULARIZED_CORRECTION_ACCEPT`、`SRM_NUMERICAL_ABORT`、`FIXED_FS_REJECT`、`NEWTON_WATCHDOG_ACCEPT`を記録する。P1説明の開始行は154に移し、診断と重ならないようにした。要素接線の対称誤差を毎回計測し、分解／求解の時間には回復補正の費用も含める。

## 文献斜面の確認

Griffiths–Laneの乾燥斜面（200 Q8要素、2×2 Gauss、E=100000・ν=0.3・γ=20・c=10・φ=20°・ψ=0）を使い、固定Fsで全自重を載せる検証を行った。固定Fsは入力値であり、求めた崩壊安全率ではない。

|---|---:|---|---:|---:|---:|---:|
|INCO_11|1|PASS|6.033e-12|0.380630|0.381|-0.10%|
|INCO_11|1.2|PASS|1.005e-07|0.427325|0.422|+1.26%|
|INCO_11|1.3|PASS|4.499e-06|0.467605|0.453|+3.22%|

INCO_11は施工・RCM・除荷の修正前の途中版で、当時の配布版と分けて記録した。当時の配布版と同じSHA256の結果はINCO_14の行である。δは本ブックの最大絶対自由度変位であり、論文の変位定義との厳密な対応は未確定。近限界の差はメッシュ・載荷経路・安定化・変位定義も含めて追加検証が必要である。

以前の3段先行試行ではFs=1.35のλ≈0.996で停滞しFSSを無効化した。その記録も集計に残した。6段の先行試行は途中版でFs=1.35の全載荷まで進んだが、通常のFs=1・1.2・1.3では費用が増える場合がある。近限界の収束改善のための方策であり、一律の高速化として扱わない。

450要素の試作ではFs=1の自重段階が完了した。後続のFs=1.2は改修版への切替のため中断し、最終配布版の細かいメッシュ・全探索は未検証である。中断を非収束・破壊判定の結果として集計していない。

## 検証の限界

材料点・線形ソルバの合格は、任意の斜面での収束や破壊形状の再現を保証しない。特にψ=0の文献斜面について、Fs=1の完走だけでSRM全体を実務検証済みと扱わない。固定Fsと全探索、部分載荷と全自重、数値収束境界と力学的破壊を分けて比較する。今回の全体ケースの成否と数値は検証集計を参照する。フルモデルの速度測定は含めない。文献ケースの計時も単発で並行検証を含み、速度比較用のベンチマークではない。

比較に試した広い単調ラインサーチ、弾性回復、単純な残差勾配、非単調残差窓は停滞が残ったため配布経路に含めない。増分上限を一律0.05にする試作は細かいメッシュで改善を確認できず、配布版では元の上限0.2を保持した。中止した試作の部分載荷は、計算失敗や安全率の測定値として扱わない。
